# FASTQ to BAM Conversion Skill

## Purpose

Convert FASTQ/FASTA files into BAM format.

This skill wraps the internal conversion script:
/root/projects/gsda/gseda/src/gseda/file_format_cvt/fastq2bam.py

The script converts sequence files into BAM format.

---

## When to use

Use this skill when the user requests:

- convert fastq to bam
- fastq2bam
- generate bam from fastq
- transform FASTQ/FASTA files into BAM

---

## Input

Required:

- Input FASTQ or FASTA file path

Example: 
  sample.fastq

## Output

The output BAM file is generated by replacing the input file extension with `.bam`.

Examples:
  sample.fastq -> sample.bam


## Execution

Run:

```bash
python3 /root/projects/gsda/gseda/src/gseda/file_format_cvt/fastq2bam.py \
    <input_file> \
    <output_bam>
