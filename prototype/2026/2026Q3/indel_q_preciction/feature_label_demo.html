CCS 三类错误预测 — 特征与 label 示例

同一分子上 3 条 subreads 与 SMC 一致序列、reference（Sanger，视为真值）的玩具比对。 三类错误住在不同列类型里、互斥：M 列 / I 列 / D 列分别喂给 SNP / 插入 / 删除三个二分类模型。 点击任意列查看该位点进入 GBDT 的窗口特征与 label 推导。

比对与 label

Model B 只在 SMC 为 − 且 subreads 有覆盖的列打分（候选位点）；Model A 只看 M 列；Model C 看 SMC 有碱基的列（M+I）。 每个模型输出的 label 由该列类型决定，互不重叠。

目标位点特征

  • 前提：reference = 该分子的 Sanger 真值，因此「consensus 相对 ref 的差异」即错误。
  • 列类型：M（SMC、ref 均有碱基）；I（ref 无碱基，SMC 多 call）；D（ref 有碱基，SMC 漏 call）。
  • label：A 在 M 列判 SMC≠ref；B 在候选列判 ref 是否被漏 call；C 判是否为 I 列。三个模型独立训练，输出三个独立 Q 通道、不归一。
  • 特征：窗口 [t−k, t+k] 内每列 subread 碱基计数(A/C/G/T/−) + SMC 碱基 one-hot + 上下文标量（均聚长度、到最近 gap 距离、深度、pass 数 N）；Model B 额外加 subread 支撑度。

示意图例：数据为虚构玩具比对，仅用于说明特征与 label 的对应关系。碱基颜色为基因组学惯例色并通过 CVD 校验；每格始终显示碱基字母，颜色为冗余副编码。
