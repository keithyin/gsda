# 05　合规性评估与验证方法

> 本文档回答：**怎么证明"平台测序分型结果"符合 GB/T 39914-2021 的要求？** 分两层：
> ① 平台分型结果**本身准不准**（分析质量验证）；
> ② 平台分型结果**能不能套用国标判定**（合规性论证）。
> 以及最终评估报告里要写什么。

---

## 1. 评估的三个层面

| 层面 | 问题 | 方法 |
|---|---|---|
| **A. 分型准确性** | 平台测出的等位基因对不对？ | 与 Sanger/CE/consensus 对照；reads 支持度、深度、重复性 |
| **B. 与国标可比性** | 换算后的"片段大小"能不能对国标 Bin？ | 桥 A 模拟长度 vs 附录 B 范围；CE 校准（桥 C） |
| **C. 判定合规性** | 能不能按国标规则下真实性/纯度结论？ | 差异位点 ≤2、纯度容差、报告格式符合第 10 章 |

---

## 2. 层面 A：分型准确性验证

### 2.1 与 Sanger（ab1）对照

平台为每个 consensus 生成了 **ab1 Sanger 峰图**（160 个文件）。Sanger 是"金标准"级别的验证手段。对每个有 Sanger 的位点：

- 提取 ab1 的碱基序列；
- 与平台 consensus / 我们分型出的等位基因比对；
- 计算一致率。

> 意义：Sanger 一致 → 平台 consensus 和我们的分型都可信。

### 2.2 与平台 consensus / frequency_table 对照

对平台已有 consensus 的样品×位点，用我们的分型结果与其比对：

- consensus 的 SSR 重复次数 vs 我们调用的等位基因；
- frequency_table 中 SSR 区的深度/频率 vs 我们统计的支持率。

### 2.3 reads 支持度与重复性

- **深度**：每样品×位点 reads 数（建议 ≥10，最好 ≥30）。
- **支持率**：主等位基因 reads 占比。
- **重复性**：同一（样品×位点）在批次内重复样品间结果一致（若客户有重复样）。
- **质控表**：输出每样品×位点的深度、支持率、可疑标记，作为报告附件。

### 2.4 判定准确性阈值（建议，需数据校准）

| 指标 | 合格线（建议） |
|---|---|
| Sanger 对照一致率 | ≥ 99% |
| 位点深度 | ≥ 10 reads（缺失判定另计） |
| 主等位基因支持率 | ≥ 85%（纯合）；双等位基因各 ≥20%（杂合） |
| 样品位点检出率 | ≥ 95%（40 位点中被成功分型的比例） |

## 3. 层面 B：与国标可比性验证（桥 A / C）

### 3.1 桥 A 验证：模拟长度 vs 附录 B 范围

对每个位点，把模拟出的"国标扩增子长度"分布与**附录 B 表 B.1 的范围/片段定义**对比：

```
位点 PM01 (bnlg439w1): 国标范围 320~368 bp，已知片段 320/322/325/...
我们模拟的分布：约 320、322、350 … → 落在国标片段定义上 → ✅ 可比
若系统性偏移（如整体 +6 bp）→ 检查引物坐标或需 CE 校准
```

**验证标准**：≥90% 位点的模拟长度能归入附录 B 定义的片段（±1 bp）。

### 3.2 桥 C 验证：与 CE 结果一致性（有 CE 时）

若同批样品有 CE 检测结果（推荐）：

1. **校准**：每个位点拟合"平台模拟长度 → CE 片段大小"偏移（多数位点 CE 与序列长度差 1~3 bp）；
2. **一致性**：平台分型等位基因 vs CE 等位基因的**一致率**（逐位点、逐样品）；
3. **差异位点吻合**：平台判"差异位点"与 CE 判"差异位点"是否一致。

**报告写法**：
> 平台测序分型结果与国标方法（毛细管电泳）检测结果在 N 个样品×位点中一致率为 X%；不一致位点集中于 __（如 SSR 长度接近 Bin 边界）__。

### 3.3 平台等价性论证

国标 5.3.3 允许"在适于检测目的和不影响检测质量的前提下，对技术条件做适宜的局部改进"。平台用测序替代电泳，属于方法改进，论证要点：

- 位点一致（PM01~40 与国标相同）；
- 等位基因可换算到国标 Bin（桥 A 验证）；
- 分型准确率达标（层面 A）；
- （如有）与 CE 结果一致性达标（桥 C）。

> 最终"是否被认可为符合国标"，由**出具报告/接受报告的机构**认定（客户、检测机构或主管部门）。平台侧应提供上述证据链。

## 4. 层面 C：判定合规性（按国标规则执行）

### 4.1 真实性验证（9.1）

```
差异位点数 ≤ 2 → 真实性成立
> 2 → 不成立
（序贯：I组≥3即停；否则凑40个再判）
```

**注意**：差异位点计算必须基于"与标准样品逐位点比较"，标准样品来源需确认（见 07）。

### 4.2 纯度测定（9.2）

```
异常个体识别 → 纯度(%) = 正常个体数 ÷ 总数 × 100% → 查 GB/T 3543.1 容差
```

**前提**：96 样品为独立个体、品种明确、筛选出适用的纯度引物。

### 4.3 报告合规（第 10 章）

- 报告能填入国标模板（见 06）；
- 注明：非国标引物（平台引物）名称及序列、样品数量是否达标、与指纹平台比对情况等。

---

## 5. 评估报告结构建议

```
《XX 平台玉米品种 SSR 检测结果与 GB/T 39914-2021 符合性评估报告》
一、评估目的与依据（国标、样品信息）
二、平台检测方法与数据概况（测序方案、96样品、40位点）
三、分型结果（40位点基因型表，含深度/支持率）
四、分型准确性验证（Sanger/consensus/CE 对照结果）
五、与国标可比性验证（桥A模拟长度 vs 附录B；CE校准）
六、判定结果（真实性：差异位点数+结论；纯度：异常个体+纯度%）
七、质控清单与异常说明
八、结论：平台结果是否符合 GB/T 39914-2021 要求
九、附件（位点注解、引物序列、质控表、ab1/consensus 对照）
```

## 6. 质控检查清单（逐样品执行）

| 检查项 | 通过条件 |
|---|---|
| 每样品 read 数 | ≥ 1000 |
| 位点检出率 | ≥ 95%（40 位点） |
| 位点深度 | ≥ 10 reads |
| 主等位基因支持率 | ≥ 85% |
| 模拟长度 vs 附录B | ≥90% 位点落入 Bin |
| Sanger 对照一致率 | ≥99%（有 Sanger 的位点） |
| 与 CE 一致率（如有） | ≥ 约定阈值（建议 ≥98%） |
| 差异位点可追溯 | 每位点有明确等位基因证据 |
