# 01　GB/T 39914-2021 标准要求解读（玉米 SSR 检测）

> 本文档把国标 **GB/T 39914-2021《主要农作物品种真实性和纯度SSR分子标记检测 玉米》** 的要求逐条拆解，作为本项目"平台输出是否符合国标"的判定依据。
> 标准全文见 `corn-ssr-standard.md`。看不懂的术语先查教材第 9 章名词表。
> 本文标注【★】的是**直接影响合规判定**的条款，务必牢记。

## 2. 适用范围（第 1 章）

- 规定了玉米（*Zea mays* L.）品种**真实性**和**品种纯度** SSR 分子标记的**检测原则、检测方案、检测程序和结果报告**。
- 适用于**品种真实性验证**和**真实性身份鉴定**。
- **不适用**：实质性衍生品种（EDV）、转基因品种的鉴定。
- 纯度测定：适用于**单交种**；自交系、双交种、三交种可**参照执行**。

> 【★】本项目的样品若用于纯度测定，需要确认是单交种（杂交种）类型。

---

## 3. 关键术语（第 3 章）

| 术语 | 定义（标准原文提炼） | 对本项目的意义 |
|---|---|---|
| **品种真实性验证** | 与"标准样品"比较，证实样品品种名称标注是否名副其实 | 判定"是或不是" |
| **品种真实性身份鉴定** | 经 SSR 检测并通过"SSR 指纹数据比对平台"筛查，确定真实品种名称 | 判定"是谁" |
| **标准样品** | 国家指定机构保存的、代表审定品种特征特性的实物种子样品 | 真实性验证的比对对象 |
| **SSR 指纹数据比对平台** | 用标准化方法检测品种等位基因，构建的审定品种分子数据检索比对系统 | 身份鉴定用（品种指纹库） |
| **参照样品** | 等位基因片段大小已知、用于校准检测样品片段的样品 | 每次电泳"校尺子"用 |
| **组合引物 panel** | 可组合一起电泳的荧光标记引物组 | 多重 PCR / 多重电泳 |
| **等位基因 allele** | SSR 检测中，等位基因差异以**扩增产物片段大小**表示 | 分型结果的基本单元 |
| **Bin** | 一个已定义片段大小的区间范围，用于把连续长度归入离散等位基因 | 长度→等位基因的"取整" |

## 4. 检测方案（第 5 章）——引物、平台、样品、条件

### 4.1 引物体系【★】

**真实性鉴定引物（表 1）：40 对核心引物 PM01~PM40**

- 依据"高分辨率、染色体均匀分布"等原则从我国审定玉米品种中遴选，覆盖 **10 条染色体**（每条约 4 个）。
- 分 **I 组（PM01~PM20）**、**II 组（PM21~PM40）**，每组 20 对。
- 等位基因扩增片段范围（附录 B）：**126 ~ 430 bp**（各引物范围见附录 B 表 B.1）。
- 标记荧光：NED/PET/FAM/VIC（仅示例，因平台而定）。

**引物使用策略（5.2.1）**：

| 目的 | 引物策略 |
|---|---|
| **真实性验证**（重点是否定的判断） | 可**序贯**：先测 I 组（PM01~20）。若已检出"足以判不符"的差异位点数（≥3）→ 终止；若检出但未达（0~2）→ 继续测 II 组，40 个位点凑齐再判定 |
| **真实性身份鉴定**（重点肯定的判断） | 尽量用 40 对全测，与指纹平台比对；仍无法区分时允许用其他 SSR 标记 |

**纯度测定引物（表 3）：8 对候选引物**（PM01/PM08/PM13/PM15/PM17/PM20/PM23/PM31）

- 针对异常个体类型（自交 / 异交 / 混杂）筛选 1~3 对以上引物（见 8.2.1）。
- 筛选原则：能准确识别该品种的异常个体，兼顾杂合度、DNA 快速提取、多重组合电泳潜力。
- 筛选时用至少含 **20 粒**的小样品预试验。

### 4.2 检测平台（5.3）

| 平台 | 适用 | 注意 |
|---|---|---|
| **毛细管电泳（CE）** | 真实性 + 纯度（推荐，精度 1 bp，≤10 重组合） | 数据可与指纹平台比对 |
| **变性 PAGE 电泳** | 真实性 + 纯度 | 数据难与指纹平台比对（只能做验证） |
| **琼脂糖电泳** | 仅纯度（需等位基因片段差异 >20 bp） | 分辨率低 |

> 5.3.3：在"适于检测目的、不影响质量"前提下，允许对标准的技术条件做**适宜的局部改进**。这是平台方法（测序替代电泳）能否被接受的重要依据——但需要论证"等价或更优"。

### 4.3 样品要求（5.4）【★】

**真实性鉴定（5.4.1）**

- 送验样品为种子：质量 ≥ **200 g** 或 ≥ **500 粒**；田间取果穗 ≥ 5 个（总粒数 ≥500 粒）。
- 组织取样：幼苗/叶片/苞叶 ≥ **20 个个体**（混合样需先单独提 DNA 再等量混合）。
- 试样：混合样 ≥ **20 个个体**；单个体试样 ≥ **5 个个体**。

**纯度测定（5.4.2）**

- 杂交种：≥ **200 g** 或 ≥ **500 粒**；自交系：≥ **400 g** 或 ≥ **1000 粒**。
- 试样：**单个个体独立检测**；杂交种 ≥ **96 × 2 粒**（可含对照）；自交系 ≥ **96 × 4 粒**。
- 取样符合 GB/T 3543.2 规定。

> 【★】纯度测定必须"单粒/单株独立检测"，数量要求 96×2 或 96×4。本项目 96 个 barcode 若对应 96 个独立个体，数量正好接近要求，但要确认每个样品是单粒来源。

### 4.4 检测条件（5.5）

- 检验员技能、仪器校准、试剂等级、使用校准参照样品。

## 5. 真实性检测程序（第 7 章）

### 5.1 引物合成（7.1）

- PAGE：普通引物；荧光 CE：正向引物 5′ 端标记荧光（NED/PET/FAM/VIC）。

### 5.2 DNA 提取（7.2）

- 方法：CTAB / 试剂盒 / SDS / 碱煮法任选（纯度测定优先碱煮法）。
- 质量要求【★】：**OD260/280 宜 1.8~2.0**，DNA 无降解。

### 5.3 PCR 扩增（7.3）

- 反应体系（表 2）：MgCl₂ 终浓度 2.5 mmol/L、dNTP 0.15 mmol/L（每种）、Taq 0.05 U/μL、引物 0.25 μmol/L、DNA 2.5 ng/μL。
- 反应程序：94℃ 5 min 预变性；(94℃ 40s → 60℃ 35s → 72℃ 45s) × 35；72℃ 10 min 终延伸。

### 5.4 扩增产物分离（7.4）

- CE：≤ **10 重**组合引物电泳；96 孔板加 1 μL 混合产物 + 0.1 μL 内标 + 8.9 μL 甲酰胺，95℃ 变性 5 min。
- PAGE / 琼脂糖见标准原文。

### 5.5 数据分析（7.5）【★——判定前最重要的质控环节】

**峰型甄别规则（毛细管电泳）**——按"以峰高为主、兼顾峰型"：

| 峰型 | 处置 |
|---|---|
| 连带（pull-up）峰 | 预先消除干扰再分析 |
| (n+1) 峰（相距 ~1 bp 的两个峰） | 视为单峰 |
| 连续多峰（相差一个重复单元的连峰） | 视为单峰，取最右峰，峰高叠加 |
| 多个特异峰 | 只采前两位的两个峰 |
| 高低峰 | 设定阈值，低于阈值的峰不采 |

**基因型读取**：纯合 = 单峰/单带；杂合 = 双峰/双带。
- 数据记录格式【★】：纯合 `X/X`，杂合 `X/Y`（小在前），缺失 `0/0`。

**数据比对方式（7.5.3）**：
- 与**标准样品**在同一电泳板逐位点两两比较 → 确定差异位点。
- 与**SSR 指纹数据比对平台**在线逐位点比对。

**异质性处理（7.5.1.4）**：混合样在位点出现异质性无法识别特异谱带的 → 改为单个体检测（≥20 个）；若**一半以上**位点明显异质性 → 可终止真实性鉴定。

> 【★】这些"峰型甄别规则"在测序数据里对应的是：reads 中出现 ±1 重复单元（stutter）、低频变异、串联重复区读长波动等，分析时要有等价的过滤逻辑（见 04 文档）。

## 6. 品种纯度检测程序（第 8 章）

- **DNA 提取**：优先碱煮法（8.1）。
- **引物筛选（8.2）**：
  - 自交个体（母本有、父本缺失）：筛 1 对检测杂合位点的引物；
  - 异交个体（母本有、父本错误）：有父母本对照时筛 2 对以上；
  - 混杂个体（父本有、母本错误或均无）：筛 2 对以上；
  - 同时鉴定多种类型：综合考虑筛 3 对以上。
  - 推荐 8 对候选（表 3）；不够可再用表 1 其余 32 对或其他引物。
- **PCR / 电泳 / 数据分析**：同第 7 章。

## 7. 结果计算与表示（第 9 章）——判定规则【★】

### 7.1 真实性鉴定（9.1）

```
统计差异位点数（检测样品 vs 标准样品逐位点比较）
```

> **【★】判定：检测结果的容许差距不能大于 2 个等位位点。**
>
> 即：**差异位点数 ≤ 2 → 真实性成立（同一品种）；> 2 → 真实性不成立。**

配合序贯逻辑（5.2.1.2）：
- 先测 I 组 20 个位点：
  - 差异位点 ≥ 3 → 直接判不符，终止；
  - 差异位点 0~2 → 继续测 II 组；
- 40 个位点全测后，总差异位点 ≤ 2 → 成立，否则不成立。

### 7.2 纯度测定（9.2）

- 结果表示方式（任选其一）：
  1. 用异常个体数目表示（自交个体数、其他异常个体数）；
  2. 用正常个体数占检测总数的**百分率**表示。
- **纯度 = 正常个体数 ÷ 检测总数 × 100%**。
- **【★】容许差距应符合 GB/T 3543.1 的要求**（抽样容差表，判定"该纯度是否达标"时查表）。

## 8. 结果报告（第 10 章）【★——平台报告要能填进这些模板】

### 8.1 真实性验证填报

> a) 通过 ____ 对引物，采用 ____ 电泳方法进行检测，与标准样品比较**未能检测出位点差异**。
>
> b) 通过 ____ 对引物，采用 ____ 电泳方法进行检测，与标准样品比较检测出差异位点数 ____ 个，差异位点的引物编号为 ________。

### 8.2 真实性身份鉴定填报

> 通过 ____ 对引物，采用 ____ 电泳方法进行检测，经与 DNA 指纹数据比对平台筛查并鉴定，检测样品属于 XXX 品种，或者属于 XXX、XXXX 其中的一个。

### 8.3 纯度测定填报

> a) 通过编号为 ____ 的引物，检测了 ____ 个个体，采用 ____ 电泳方法，检测出自交个体 ____ 个，其他类型杂株个体 ____ 个。
>
> b) 通过编号为 ____ 的引物，检测了 ____ 个个体，……检测出自交个体和其他类型杂株个体 ____ 个，品种纯度为 ____%。

### 8.4 需在报告中注明的特殊情况

- 送验样品低于 5.4.1.1 / 5.4.2.1 规定数量的；
- 与 DNA 指纹数据比对平台比对数据的；
- 检测样品遗传不稳定严重的位点（引物编号）清单；
- 采用其他 SSR 引物的名称及序列。

> 【★】平台如果用**自己设计的引物**（而非国标表 1 原始引物），属于"采用了其他 SSR 引物"，**必须在报告中注明引物名称及序列**——这是平台合规报告绕不开的点。

## 9. 附录要点

- **附录 A（规范性）**：溶液配制（CTAB/SDS/NaOH 提取液、TE、PAGE 胶、TBE/TAE、银染液等）。
- **附录 B（资料性）**：**表 B.1 已知品种主要等位基因扩增片段信息**——40 对引物在已知审定品种中的片段范围、定义、频率，以及**参照样品**（如郑单958、先玉335、农大108 等）对应片段。**这是把平台"模拟长度"归入 Bin 的核心对照表。**

## 10. 判定要诀速查卡

| 检测类型 | 用什么比 | 判定标准 |
|---|---|---|
| 真实性验证 | 检测样品 vs 标准样品 | 差异位点数 **≤2** → 成立 |
| 真实性身份鉴定 | 检测样品 vs 指纹数据平台 | **零差异**匹配 → 确定品种 |
| 纯度测定 | 单粒个体的异常识别 | 异常个体比例 + **GB/T 3543.1 容差** |

| 硬性要求 | 数值 |
|---|---|
| 核心引物数 | 40 对（PM01~40，I 组 20 + II 组 20） |
| 等位基因片段范围 | 126~430 bp（附录 B） |
| 真实性取样 | 种子 ≥200 g 或 ≥500 粒；混合样 ≥20 个体 |
| 纯度取样 | 杂交种 ≥96×2 粒；自交系 ≥96×4 粒（单粒独立检测） |
| DNA 质量 | OD260/280 = 1.8~2.0 |
| 记录格式 | 纯合 X/X、杂合 X/Y、缺失 0/0 |
| 报告注明 | 采用非国标引物时必须注明名称及序列 |
