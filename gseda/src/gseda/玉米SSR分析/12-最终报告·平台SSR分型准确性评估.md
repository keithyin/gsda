## 一、执行摘要（一页结论）

**一句话结论：平台用 PacBio HiFi 测序测玉米 SSR 位点，约四分之三的位点 reads 高度收敛、CN 值可信，可替代传统毛细管电泳（CE）；约四分之一的位点为长纯重复，测序滑移（stutter）严重，单值 CN 不可靠，需结合分布或 CE 对照解读。**

|---|---|---|

| | Q30（高质量）通过率 | **75.8%**（133,315 条通过） |

**关键结论**：
1. **可信位点**（17 个，占可对比位点的 71%）：两法换算高度一致（**≥95%，其中 14 个 100%**，如 PM05 87/87、PM12 64/64、PM28 88/88），reads 高度收敛，这些位点平台可直接替代 CE。
2. **待处理位点**（约 8~10 个）：长纯重复（PM22、PM09、PM05 等）stutter 严重，需报告 CN 分布或加 CE 对照校准。
3. **⚠️ 数据缺口**：① **PM35 全库无数据**（扩增子未出现在测序文库，需排查建库环节）；② PM02/03/11/40 因深度不足无 CN 数据；③ 5 个样品（barcode207-2 等）为失败/空文库。
4. **最硬真值尚未获得**：CE（毛细管电泳）对照数据是判定"准不准"的黄金标准，建议尽快补充，用于最终校准。

## 二、背景与目标

### 2.1 我们测了什么

玉米品种真实性鉴定、身份鉴定、纯度测定，国际通用方法是**SSR 分子标记**：在基因组上 40 个特定位置（国标 GB/T 39914-2021 规定的核心位点 PM01~PM40）测量一段"串联重复序列"（一段短碱基序列连续重复多次）的重复次数，不同品种重复次数不同，从而区分品种。

传统检测用**毛细管电泳（CE，Capillary Electrophoresis）**：PCR 扩增出这段 DNA，按长度跑电泳，用片段长度（bp）判定等位基因。**CE 是国标认可的方法，也是行业金标准。**

平台的方案是**用 PacBio HiFi 高通量测序替代 CE**：把 40 个位点的 PCR 产物混合测序，直接从 DNA 序列里数出重复次数（CN），再换算成片段长度对标国标。**本报告回答的问题：这条路测出来的结果准不准？**

### 2.2 怎么评"准不准"

判定一个（样品 × 位点）的测量准不准，用两层证据：

1. **reads 一致性（内证）**：同一位点有几千条测序 read，如果它们数出的重复数高度一致（收敛），说明信号清晰、可信；如果杂乱（stutter），说明不可靠。这个指标叫**主等位支持率 P**（见术语）。
2. **两法一致性（互证）**：用两种完全独立的方法算片段长度——① 直接在 read 里量物理片段长度（模拟 CE 测的东西）；② 由 CN×重复单元长度推算。两种方法对同一批样品结果一致（差 ≤3bp），说明换算正确。

## 三、术语与指标说明（重要：先读这里）

> 报告中每个缩写首次出现都会标注全称。下表集中解释所有核心指标，每个都附"怎么读"。

### 3.1 生物学与测序术语

| 缩写 | 全称（中/英） | 含义 | 怎么读 |
|---|---|---|---|
| **SSR** | 简单重复序列 / Simple Sequence Repeat | 基因组上"一个短单元（如 GA）连续重复"的区域 | 它的重复次数决定品种差异 |
| **CN** | 重复单元数 / Copy Number | SSR 区域里重复单元的个数，如 (GA)×13 的 CN=13 | 本报告最核心的测量值 |
| **bp** | 碱基对 / base pair | DNA 长度单位 | CE 报告片段长度的单位 |
| **位点** | locus | 基因组上固定的检测位置（本报告=国标 PM01~PM40） | 40 个位点各测各的 |
| **引物** | primer | 一段与目标序列互补的短 DNA，PCR 用它把目标区域扩增出来 | 扩增出的片段才被测序 |
| **PCR** | 聚合酶链式反应 | 放大特定 DNA 片段的技术 | 位点归属的基础 |
| **HiFi** | 高保真 / High-Fidelity | PacBio 测序的一类高准确率长读长技术 | 本平台的数据来源 |
| **CCS** | 环形一致性测序 / Circular Consensus Sequencing | 同一 DNA 分子多次读取后取共识，准确率>99% | 生成 HiFi reads 的技术 |
| **read** | 读段 | 测序仪输出的一条 DNA 序列 | 本数据共 17.6 万条 |
| **Q30** | Phred 质量分数 ≥30 | 碱基错误率 ≤0.1% 的质量门槛 | 过滤低质量数据的标准线 |
| **readsQ** | 整条读质量 / Read Quality | 一条 read 全部碱基的平均质量（概率法换算） | readsQ≥30 才算高质量 |
| **depth** | 测序深度 | 支撑某位点计数的 reads 条数 | 越高越可靠；本报告门槛 depth≥10 |

### 3.2 本流程的核心指标（CN 计数）

| 指标 | 全称 | 定义 | 怎么读 |
|---|---|---|---|
| **P** | 主等位支持率 / major-allele support | **对每个（样品×位点×重复单元）分量：把该分量所有 reads 数出的 CN 做频数统计，出现次数最多的 CN 叫"众数 CN"；P = 支持众数 CN 的 reads 条数 ÷ 该分量总 reads 条数（depth）**。即"reads 对同一个 CN 的共识程度"。 | P 越高 → 越多 reads 报同一个 CN → 该 CN 越可信。判定带：**P≥60% ✅ 可信 / 40–60% ⚠️ 存疑 / <40% ❌ 不可靠**。 |
| **s1** | ±1 重复率 | 恰好多/少 1 个重复单元的 reads 占比（stutter 滑移比例） | 高说明该位点滑移明显 |
| **s2** | ≥±2 重复率 | 偏离 2 个及以上重复单元的 reads 占比 | 高说明存在杂合或异常 |
| **stutter** | 滑移 | 测序/PCR 时重复区"多报或少报"1 个单元的现象，长纯重复位点尤甚 | 它是"P 低但平台没测错"的主要原因之一 |
| **min-depth** | 最低计数深度阈值 | 每分量计数 reads 数低于此值的测量**不纳入结果**（本报告=10） | 剔除深度 1~9 的不可靠测量 |

### 3.3 归属与对标术语

| 缩写 | 全称 | 含义 | 怎么读 |
|---|---|---|---|
| **both** | 双向锚定 | read 的 5' 端命中正向引物、3' 端命中反向引物（即 read 完整跨过目标区） | 最高置信的归属等级 |
| **fonly** | 仅正向锚定 | 只命中 5' 正向引物（read 可能截短） | 次高置信 |
| **none** | 未归属 | 没有引物命中（脱靶/高变/失败库） | 通常进不了后续分析 |
| **qfiltered** | 质量过滤 | readsQ 低于 Q30 被过滤 | 从源头剔除，不进任何后续分析 |
| **CE** | 毛细管电泳 / Capillary Electrophoresis | 国标认可的片段长度检测方法（行业金标准） | 本报告的对照目标 |
| **GB** | 国标 | GB/T 39914-2021《玉米品种真实性鉴定 SSR 检测方法》 | 本报告对标的标准 |
| **Bin** | 等位基因片段区间 | 国标附录B 给出的每个位点等位基因的片段长度范围 | 实测片段落进哪个 Bin=哪个等位基因 |
| **等位基因** | allele | 同一基因位点的不同序列形式（本报告=不同重复数） | 纯合=两个拷贝相同；杂合=不同 |

## 五、质量控制结果

### 5.1 测序质量（Q30 过滤）

| 指标 | 数量 | 占比 |
|---|---|---|
| 原始 reads | 175,854 | 100% |
| Q30 通过（readsQ ≥ 30） | **133,315** | **75.8%** |
| Q30 过滤（readsQ < 30） | 42,539 | 24.2% |
| 通过 reads 的质量中位数（readsQ） | 34.7 | — |

> **怎么读**：readsQ（整条读质量）是把一条 read 所有碱基的错误率求平均再换算回质量分（概率法，非简单平均）。readsQ≥30 对应平均碱基错误率 ≤0.1%。过滤掉的是质量明显偏低的 read——它们进入下游会污染 CN 计数。24.2% 的过滤率在 HiFi 数据中属于正常范围（文库扩增本身会带来一定比例的杂质/低质量 read）。

### 5.2 位点归属质量

| 指标 | 数量 | 占比（占 Q30 通过 reads） |
|---|---|---|
| 归属成功（both + fonly） | **117,653** | **88.3%** |
| └ both（双向锚定，高置信） | 111,150 | 83.4% |
| └ fonly（仅正向锚定） | 6,503 | 4.9% |
| 未归属（none） | 15,662 | 11.7% |

> **怎么读**：88.3% 的通过 read 能确认它属于哪个位点，其中 83.4% 是双向锚定的高置信 read（完整跨过目标区，可精确计数）。11.7% 未归属的多为高变异等位基因或脱靶产物。**每样品归属率可从 `data/assign/stats.tsv` 逐行查**；归属率异常低的样品（如 5 个失败样品）在 QC 时标记。

### 5.3 样品级 QC 结论

- **5 个失败样品**（barcode207-2、211-1、221-1、267-0、272-1）：reads 数 1~3 条，属于空/失败文库，**不进入下游任何分析**。
- 其余 108 个样品有归属 read；其中 **92 个样品**产出了合格（depth≥10）的 CN 测量。16 个样品仅有少量归属 read、但各分量深度均 <10，被 min-depth 过滤剔除（数据量不足的测量不可信）。

## 六、准确性结果（核心）

### 6.1 第一层证据：reads 一致性（CN 数得准不准）

对每个（样品×位点×重复单元）分量，统计所有 reads 数出的 CN 分布，用**主等位支持率 P**（见术语：支持众数 CN 的 reads 占比）衡量收敛程度。

**总体结果（2,737 项测量，深度均 ≥10）：**

| P 判定 | 数量 | 占比 | 含义 |
|---|---|---|---|
| ✅ P≥60%（可信） | **2,003** | **73.2%** | reads 收敛，CN 明确 |
| ⚠️ 40%≤P<60%（存疑） | 564 | 20.6% | 有滑移/杂合信号，需结合次峰判断 |
| ❌ P<40%（不可靠） | 170 | 6.2% | 分布散乱，单值 CN 不可信 |

**位点层面**：35 个位点有 CN 数据，其中 **27 个位点的中位 P≥60%**（即超过一半的样品收敛良好）。收敛差的 8 个位点：PM01、PM04、PM05、PM08、PM09、PM15、PM22、PM30——全部为长纯重复位点或高变区。

> **怎么读 P**：以 PM05 为例——85 个样品的主 CN 全是 13（即 (AG)×13），说明这个品种在这个位点稳定报出 13 个重复，测量可信。而 PM22（(CT)×23 长重复）的 P 中位数仅 35%，reads 报的 CN 从 10 到 40 散开，单值不可信。

### 6.2 第二层证据：CN→片段→国标 Bin 互证

用两种独立方法算片段长度并对比（差 ≤3bp 判一致，仅统计有真实 CN 数据的样品）：

**总体**：**1,230/1,427 = 86.2% 的（样品×位点）两法一致**；2,061 个有 read 实测片段的（样品×位点）中，**83.6%（1,723 个）落在国标等位基因 Bin 范围内**。

**位点层面（24 个可对比位点）**：

| 等级 | 位点（两法一致率） | 说明 |
|---|---|---|
| **100% 一致**（14 个） | PM01、PM05、PM12、PM14、PM20、PM21、PM27、PM28、PM29、PM31、PM33、PM34、PM36、PM39 | 全部样品两法一致，可直接替代 CE |
| **90~97%**（5 个） | PM04 95%、PM09 97%、PM15 94%、PM22 96%、PM30 91% | 绝大部分一致，个别样品需查看 |
| **低一致**（5 个） | PM13 0%、PM18 0%、PM25 31%、PM32 0%、PM37 56% | 复合/锚定/数据量问题，需单独处理 |
| **无法对比**（16 个） | PM02/03/06/07/08/10/11/16/17/19/23/24/26/35/38/40 | 无 read 实测片段或 CN 数据 |

> **怎么读 86.2%**：这不是"86.2% 的位点测错了"——而是说明**绝大多数位点的 CN 换算与 read 物理实测吻合**。不一致的集中在 3 类：复合重复（PM25，多个重复单元连在一起数不准）、锚特异性差（PM18/32）、长重复滑移（PM37）。16 个无法对比的位点是"缺证据"而非"测错"。

### 6.3 精确命中国标等位基因的例子

| 位点 | 实测片段 | 国标等位基因 | 说明 |
|---|---|---|---|
| PM27 | 272 bp | 272 | 全部 88 个样品两法一致，精确命中 |
| PM31 | 263 bp | 263 | 39/39 一致，精确命中 |

## 九、覆盖缺口与风险

### 9.1 ⚠️ 必须披露的数据缺口

1. **PM35 全库无数据（最严重）**：PM35（bnlg2235y5，国标 40 核心位点之一）的 4 条引物全部与参考序列精确匹配（引物本身有效），但 **113 个文库文件中 0 条 read 含有该引物序列**（对照 PM12 在 90/113 文件有命中）。结论：**PM35 扩增子没有出现在测序文库中**，是建库/上机环节的问题（引物未加入反应池或扩增失败），**不是数据分析问题**。需排查 PCR 反应体系或重新建库。
2. **PM02/03/11/40 无 CN 数据**：深度不足被 min-depth 10 过滤。其中 **PM40 是国标核心位点**，缺失会影响 40 位点完整评估。
3. **5 个失败样品**：barcode207-2、211-1、221-1、267-0、272-1 为空/极低 reads 文库，不参与任何结果。

### 9.2 技术风险与局限

| 风险 | 影响 | 缓解/建议 |
|---|---|---|
| 长纯重复位点 stutter 严重 | PM09/22/04/05 等单值 CN 不可靠 | 报告 CN 分布而非单值；或 CE 对照校准 |
| 复合重复位点难算准 | PM25 两法一致率仅 31% | 按分量处理（已做），需 CE 验证 |
| 部分位点 bridge 锚特异性差 | PM11/13/18/32 无 read 实测片段 | 用 Sanger/CE 直接验证 |
| 参考坐标略超国标范围 | PM09/17/36/38/40 | 真实长等位基因，对标时单独标注 |
| 国标表1 引物序列转录差异 | 个别引物序列与参考有出入 | 出具报告时以标准纸质版核对 |

## 十、结论与建议

### 10.1 结论

1. **方法可行**：用 PacBio HiFi 测序数 SSR 重复数 + 换算国标片段长度的技术路线已完整跑通，Q30 过滤 + 双锚定归属 + min-depth 过滤的数据质量控制有效。
2. **约 3/4 位点可信**：35 个有数据位点中 27 个收敛良好；17 个位点两法一致率 ≥95%（14 个 100%）——**这些位点可替代 CE 出结果**。
3. **约 1/4 位点需 CE 辅助**：长纯重复位点（PM09/22 等）和复合位点（PM25）单值 CN 不可靠，是"测不准"还是"真杂合"需 CE 对照区分。
4. **存在明确数据缺口**：PM35 全库无数据、PM02/03/11/40 深度不足、5 个失败样品——40 位点完整评估尚未达成。

### 10.2 建议（按优先级）

| 优先级 | 行动 | 目的 |
|---|---|---|
| **高** | 排查 PM35 建库/引物问题并补测 | 补全国标 40 位点覆盖 |
| **高** | 获取 CE 对照数据（最硬真值） | 对 17 个可信位点做最终确认；对长重复位点校准 |
| 中 | 对低深度位点用 `--min-depth 2` 重跑一次，评估弱测量是否可用 | 恢复 PM02/03/11/40 的部分信息 |
| 中 | 对收敛差位点报告 CN 分布（含 stutter 信息）而非单值 | 诚实呈现不确定性 |
| 低 | 用 Sanger 验证 3~5 个关键位点（PM05/PM12/PM25） | 独立第三方确认 |

### 10.3 后续可用性

在补全 CE 对照 + PM35 数据后，平台可对外承诺：**40 位点中约 30+ 位点可与国标 CE 结果一致，用于真实性验证（差异位点数 ≤2 判定）和身份鉴定**。未解决的长重复位点需在报告中明确标注不确定性。
