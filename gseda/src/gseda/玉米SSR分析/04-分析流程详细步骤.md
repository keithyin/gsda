## 第 2 步：reads 质控过滤

目的：去掉接头串联（concatemer）、长读污染、短读碎片，只保留单个扩增子的 read。

```python
def qc_read(seq):
    L = len(seq)
    if L < 300 or L > 1500:      # 主体扩增子 400-700bp，留余量
        return False
    # 可选：去掉5'端接头序列（若有已知接头）
    return True
```

**经验参数（待调）**：主峰 400-700 bp；长度 <300 丢弃（可能是短碎片），>1500 丢弃（可能是 concatemer）。

**验证点**：统计过滤前后每样品 read 数、长度分布；确认主峰保留、长尾减少。

## 第 3 步：read → 位点映射

把每条 read 映射到 40 个位点参考序列，判定它来自哪个位点（含反向互补，因为 read 方向可能不同）。

```python
import edlib, mappy

# 方式A（推荐，先做小样）：edlib 局部比对，逐位点打分
def map_read(seq, refs):
    best, best_id = None, 0
    for locus, ref in refs.items():
        r = edlib.align(seq, ref, mode="HW", task="distance")  # 找 seq 在 ref 内最好的子串
        identity = 1 - r["editDistance"] / len(seq)
        if identity > best_id:
            best, best_id = locus, identity
    return best, best_id   # (位点, 一致度)

# 方式B（大批量更快）：minimap2 索引40条参考，映射所有read
aligner = mappy.Aligner("refs/pm_all.fa", preset="sr")
for hit in aligner.map(seq):
    pass  # hit.ctg 即位点，hit.r_st/r_en 为比对位置
```

**归属阈值**：identity ≥ **0.92** 才算可靠归属（实测 0.90+ 与 0.52 明显分群；阈值可据数据调整）。未归属 read 记录为 "unmapped"，供后续分析。

**验证点**：抽查 100 条 read 的手工核对；确认已知位点（如 PM35）的 read 一致地归到 PM35。

### 4.2 每个 (样品, 位点) 的等位基因判定

```python
# 对一个样品的某位点，收集所有 read 的重复次数（或模拟长度）
calls = Counter(repeat_counts)      # {6: 120, 7: 5, 5: 2, ...}
depth = sum(calls.values())
major, major_n = calls.most_common(1)[0]
second, second_n = calls.most_common(2)[1] if len(calls) > 1 else (None, 0)

# 判定规则（参考国标峰型甄别的精神）:
# - 主峰 + 少量 ±1 重复(read 的 "stutter" 或 PCR 滑移) → 视为纯合主等位基因
# - 两个明显等位基因且支持率都够 → 杂合 X/Y
# - 深度 < 阈值（如 <10）→ 缺失/低覆盖 0/0 或标记需重测
```

**判定规则建议（需在实际数据上调参）**：

| 情形 | 判定 |
|---|---|
| 主等位基因支持率 ≥85%，且二峰 <10% | 纯合 `X/X` |
| 两等位基因各支持 ≥20% | 杂合 `X/Y` |
| 深度 < 10 或无 read | 缺失 `0/0` |
| ±1 重复的旁峰 | 并入主等位基因（对应国标"连续多峰取最右"） |

**验证点**：对 2-3 个样品，把等位基因调用结果与同一样品的 **Sanger（ab1）/平台 consensus** 比对，确认一致。

## 第 5 步：桥 A —— 模拟"国标原始引物扩增子"长度

对每条 read，找到国标表 1 原始引物的结合位置，裁出两引物间的序列，计算长度：

```python
def simulate_std_amplicon(read_seq, priF, priR):
    # priF: 原始正向引物序列; priR: 原始反向引物序列
    f_pos = read_seq.find(priF)
    r_pos = read_seq.find(rc(priR))      # 反向引物在模板上以反向互补出现
    if f_pos >= 0 and r_pos > f_pos:
        return r_pos + len(priR) - f_pos   # 国标CE当量长度(bp)
    return None
```

- 若 read 里没有原始引物（平台扩增子边界更宽，原始引物在内），一般能找到；找不到的 read 丢弃或退回桥 B。
- 长度取众数/中位数，并记录长度分布（多峰说明有混合等位基因）。

**验证点**：模拟出的长度应落在该位点**附录 B 的范围内**（如 PM35 应 175~193 bp，实测过）。若系统性偏移，检查引物结合位点坐标是否错误。

## 第 6 步：对照 Bin，统计差异位点

把每个样品×位点的模拟长度归入附录 B 的 Bin：

```python
def bin_of(length, bins):          # bins 如 [320,322,325,331,...]
    best = min(bins, key=lambda b: abs(b - length))
    return best if abs(best - length) <= 1 else None   # ±1bp 内取整；否则标记"离Bin较远"
```

得到每个样品的"40 位点基因型向量"：

```
样品 | PM01 | PM02 | … | PM40
1    | 320/350 | 234/252 | … | 283/310
```

**与标准样品比较（真实性验证）**：标准样品 = 客户提供的已知品种指纹（或标准样品本身也用平台测一遍）。逐位点比较：

```python
def diff_loci(geno_test, geno_std):
    diffs = []
    for locus in loci:
        if geno_test[locus] != geno_std[locus]:
            diffs.append(locus)
    return diffs
```

**验证点**：差异位点列表可追溯（每位点给出两个样品的等位基因、模拟长度、深度）。

## 第 7 步：判定（按国标）

### 7.1 真实性验证（9.1）

```
差异位点数 ≤ 2  →  真实性成立（同一品种）
差异位点数 > 2  →  真实性不成立
```

序贯：先 I 组 20 个位点，≥3 个差异即停；否则测 II 组凑 40 个。

### 7.2 纯度测定（9.2，需确认 96 样品为单粒个体）

```
每个个体 = 一个样品。用筛出的 1~3 对纯度引物识别异常个体（自交/异交/混杂）。
纯度(%) = 正常个体数 ÷ 检测总数 × 100%
容许差距查 GB/T 3543.1 容差表。
```
