# 07　剩余待确认项与风险（聚焦 SSR Copy Number 准确性）

> **项目核心**：评估平台用 PacHiFi 测序测出的 SSR **copy number（重复单元数）准不准**。
> 本文档列出影响评估执行的关键未确认项与风险。优先确认项用 ★ 标注。

---

## 一、待确认项（按影响排序）

### ★1. 判断"准不准"的真值（基准）是什么

**问题**：用什么作为 copy number 的"真值"来判定平台测的准不准？

- [ ] **CE 毛细管电泳结果**（同批样品如有）：片段大小 → 换算成重复数，作为硬真值。**最有力。**
- [ ] **参考序列 / Sanger**：参考序列（Sanger 验证）的 copy number 作为真值。已有。
- [ ] **reads 一致性口径**：无外部真值时，用"reads 是否收敛到同一 copy number（主等位支持率、±1 重复率）"作为评估依据。

**影响**：决定"准不准"的判定标准。无 CE 时需确认接受参考/Sanger + reads 一致性口径。

---

### ★2. 实际使用的新引物对（F1/R1 还是 F2/R2）

**问题**：每个位点设计了两对新引物，实际 PCR 用了哪对？

**影响**：决定扩增子边界、SSR 区在 read 中的定位，以及从 read 数 copy number 时截取哪个区间。引物序列已在 xlsx 提供，只差"实际用哪组"。

---

### ★3. 样品属性与技术重复

**问题**：
- 96 个样品是独立个体还是混合样？几个品种？品种名？
- 是否有**同一 DNA 的重复测序**（技术重复）→ 评估 copy number 重复性（同一真值多次测量是否一致）？
- 样品是否为杂交种/杂合背景（解释"双峰"是杂合还是测不准需要）？

**影响**：技术重复是最直接的"准不准"证据（同一样品重测应得相同 copy number）；样品背景用于结果解释。

---

### 4. 40 位点覆盖完整性

**问题**：本批数据实际扩增/测序到位点数？抽样只见 29/40，其余位点（PM02,03,06,10,11,13,20,21,32,35,36）缺失或在他处？

**建议**：先做全量 reads 映射统计确认实际覆盖（04 文档第 3 步），再决定是否追问。

---

### 5. 交付物与结论认定

**问题**：最终要"copy number 准确性评估报告"（平台内部质控）还是要"对标国标片段大小后能否用于鉴定"？结论由谁认可？

## 二、风险分析（copy number 评估特有）

| 风险 | 说明 | 应对 |
|---|---|---|
| **R1 stutter 干扰判定** | PCR/测序在 SSR 区产生 ±1 重复的滑移产物（实测主等位支持率 62%~72%，其余 ±1~±4） | 用"主等位支持率 P + ±1 重复率 s"双指标；P≥85% 才判定明确 |
| **R2 HiFi 在长重复区系统偏差** | HiFi 可能系统性多/少数重复（尤其长重复或同聚物） | 与参考/Sanger/CE 比对检验系统性偏移 Δ；必要时校正因子 |
| **R3 双峰误判为"测不准"** | 杂合位点两个等位 ~50%，不是测不准 | 结合样品背景/其他位点判断；双峰且两峰稳定 → 判定为杂合 |
| **R4 参考序列与样品等位差异** | 参考序列是某品种的，测其他品种时 SSR 区侧翼/重复数不同 | 定位 SSR 区时以 reads 实际序列为准，不硬套参考坐标 |
| **R5 位点覆盖不全** | 40 位点未全扩增则无法全评估 | 全量覆盖统计；缺失位点注明 |
| **R6 无外部真值，说服力弱** | 无 CE/Sanger，只靠 reads 一致性 | 报告明确说明"基于 reads 一致性 + 参考比对"的评估口径 |
| **R7 引物对用错** | 影响 SSR 区定位与 copy number 计数 | 确认 F1/F2；用参考序列核对扩增子长度 |
| **R8 ±1 重复对国标片段大小的影响** | 单元 2bp 时 ±1 重复 = ±2bp，处于国标 Bin 取整临界 | 评估时把"CN 误差→片段大小→是否出 Bin"串起来 |

---

## 三、建议的行动顺序

```
1. 确认 ★1（真值口径：CE 有无 / 接受参考+Sanger+一致性）与 ★2（引物对）
   —— 决定评估标准，最先落实
2. 并行：全量 reads 覆盖统计（确认 ★4 实际覆盖）
3. 询问 ★3（样品属性 / 技术重复）
4. 按 08 文档评估流程执行：
   定位SSR靶点 → 每样品×位点数copy number → 汇总指标(P/s/Δ) → 与真值比对 → 结论
```
