## 三、❓ 待确认项（★ = 阻塞性，需优先确认）

> **本项目核心关注：平台测 SSR copy number（重复单元数）准不准。** 待确认项据此排列。

### ★B1. 判断"copy number 准不准"的真值（基准）是什么？

- [ ] **CE 毛细管电泳结果**：同批样品是否做了国标方法（PCR+CE）检测？如有，可把 CE 片段大小换算成重复数作为硬真值（最强验证）。
- [ ] **Sanger / 参考序列**：是否接受以参考序列（Sanger 验证过）的 copy number 作为真值？
- [ ] **reads 一致性**：是否接受"reads 之间是否收敛到同一 copy number（主等位支持率、±1 重复率）"作为评估依据（无外部真值时）？

> 影响：决定"准不准"用哪套标准判定。无 CE 时，用"reads 一致性 + 参考/Sanger"。

### ★B2. 实际使用的新引物对

- [ ] 每个位点实际 PCR 用的是 **F1/R1** 还是 **F2/R2**？（或两对都用/混合）
- [ ] 若不确定，能否提供实际扩增反应的引物清单？

> 影响：决定扩增子边界与 SSR 区在 read 中的定位；引物信息已在 xlsx 中提供，只需确认实际用的是哪组。

### B3. 样品属性与辅助验证

- [ ] 96 个样品是**独立个体**还是混合样？涉及几个品种？品种名？
- [ ] 是否有**同一 DNA 样品的重复测序**（技术重复）？→ 用于评估 copy number 的重复性
- [ ] 样品是否可能包含**杂合位点**（需结合品种背景，判断"双峰"是杂合还是测不准）？

> 影响：辅助验证与结果解释（双峰=杂合 vs stutter）。

### B4. 40 位点覆盖完整性

- [ ] 本批数据（Run0003 Group_0）实际扩增/测序成功了多少个位点？
- [ ] 抽样未见到的位点（PM02,03,06,10,11,13,20,21,32,35,36）是**未扩增、未测到，还是数据在其他 run/目录**？

> 说明：我们会先做全量 reads 映射统计确认实际覆盖。
