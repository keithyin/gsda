# 11　当前数据分析流程与策略（已实现，2026-08-14）

> 本文档是**当前真实跑通的分析流程**（区别于 04 的 SOP 设计稿）：从 PacBio HiFi 原始数据到 SSR copy number、再到对标国标 Bin 的完整链路。每一步给出**脚本、输入/输出、用到的策略**。
>
> 脚本都在 `scripts/`，产出在 `data/`。依赖：`edlib`。

---

## 流程总览

```
原始 CCS reads (barcodes_reads_fastq_amplicon)
      │
      ▼  ①  prepare_data.py  数据准备：docx/xlsx/国标 → 标准生信文件
  标准参考库 (refs / primers / annot)
      │
      ▼  ②  assign_reads.py  用 160 条真实引物把 reads 归属到位点
  data/assign/  (逐 read 明细 + 按样品×位点拆分的 fastq)
      │
      ▼  ③  count_cn.py  数每个 (样品×位点×SSR) 的重复单元数 (CN)
  data/cn/  (cn_summary 主表：mode CN / P / s1 / s2 / 次峰 / 判定)
      │
      ▼  ④  bridge_cn2bp.py  CN → 片段长度(bp) → 国标Bin，附录B验证
  data/bridge/  (fragment_summary / validation)
      │
      ▼  下一步（未做）：Bin 判定 → 品种真实性/身份鉴定
```

## 第 1 步　`prepare_data.py` —— 数据准备

**做什么**：把三个来源的材料整理成标准生信文件——docx 参考序列（40 位点）、xlsx 合成单引物、国标 md（表1 引物 + 附录B Bin）。

**输入**（`/data1/ccs_data/20260813-corn-ssr-analysis/`）：
- `玉米SSR参考序列及新引物PM1-20.docx`、`玉米SSR序列及引物(PM21-40).docx`
- `【海南】合成-海南测序部.xlsx` 等 3 份合成单
- `corn-ssr-standard.md`

**输出**（`data/`）：
| 文件 | 内容 |
|---|---|
| `refs/pm_all.fa` | 40 位点参考序列 |
| `primers/all_primers.tsv/.fa` | **160 条真实使用引物**（F1/R1/F2/R2）+ 结合位点 |
| `primers/gb_primers.tsv` | 国标表1 40 对原始引物 + docx 标注坐标 + 参考实际序列 |
| `annot/ssr_targets.bed` | 49 个 SSR 区域靶点（0-based，含 target 列） |
| `annot/locus_info.tsv` | 位点总表（每 SSR 分量一行） |
| `annot/primer_sites.bed` | 所有引物结合位点 |

**用到的策略**：
1. **docx 颜色标注解析**：每个位点有 3 对引物标注（黄/绿=GB 原对、青/紫=新1对、波浪/粗下划线=新2对）、红色=SSR 靶点。按 run 格式解析并合并相邻同色 run。
2. **红色标注双色兼容（关键修复）**：PM1-20 那个 docx 的 SSR 用 `EE0000`、PM21-40 用 `FF0000`，旧代码只认 FF0000 导致 17 个位点漏标 → 现在两者都识别。**红色标注 = SSR 区域权威来源**。
3. **标题行标注补收**：PM20 参考序列整段粘在标题段，标注也全部在标题行 → 专门补收标题行 run 的标注。
4. **引物定位**：序列匹配参考（edlib HW，≤2 错配），正向引物正向匹配、反向引物反向互补匹配。160/160 全部精确定位。
5. **真实使用引物溯源**：合成单的 F1/R1/F2/R2 = 真实使用集（160 条），与 GB 原对（未合成）区分开；三份合成单序列 0 差异交叉验证。
6. **SSR 靶点分类（`ssr_common.py::classify_region`）**：红色区域内部可能是简单重复（PM12 CT×10）、复合重复（PM25 CT×9+AC×6）、断裂重复（PM05/11/20 曾带内部插入/尾随碱基）——用"显著分量 ≥2"判复合 vs 简单；简单用**长度法** CN（`round(区域长/基序长)`），覆盖断裂。
7. **多靶点**：9 个位点（现 8 个）有多个不连续红色标注 → 每个独立区域编号 `target`（1=主/国标对标，2/3=次要）。
8. **算法回退**：仅无红色标注的位点用"最长重复"算法（现仅 PM20，靠标题行补收后不再需要）。

```bash
cd scripts
python3 prepare_data.py
```

## 第 2 步　`assign_reads.py` —— reads 归属

**做什么**：用 160 条真实引物，把 110 个样品的 CCS reads 归属到位点（含引物修剪、方向归一化、串联体标记）。

**输入**：`barcodes_reads_fastq_amplicon`（PacBio CCS）、`all_primers`。
**输出**（`data/assign/`）：
| 文件 | 内容 |
|---|---|
| `read_assignments.tsv` | 逐 read 明细：样品/read_id/长度/归属位点/置信级/方向/F·R位置/命中位点数/readsQ |
| `summary.tsv` | 样品×位点×read 数（both/fonly/回退分列） |
| `stats.tsv` | 每样品归属统计（含 qfiltered） |
| `split/<样品>/<PMxx>.fastq` | 方向归一化、修剪后的逐位点 read（**仅 Q30 通过 reads**，第三步输入） |

**用到的策略**：
1. **双引物锚定**：同一位置 5' 端命中 F1/F2（正向）、3' 端命中 rc(R1/R2)（反向）→ **both**（高置信，read 跨含 SSR 区）；只有 5' 命中 → **fonly**（可能截短）。edlib HW ≤2 错配。
2. **方向归一化**：约 43% 的 read 是反向互补 → 统一转成正向，保证后续计数方向一致。
3. **接头模糊修剪**：通用接头（GGCCAAAAGGAAGGCCAT）用 edlib 模糊匹配修剪，避免纯前缀匹配漏掉变体。
4. **串联体/嵌合体检测**：一条 read 命中多个位点（`n_loci`>1）→ 标记，第三步按位点分段处理。
5. **置信分级 + 回退**：`both`/`fonly`/`none` 分级；无引物命中的 read 可参考局部比对回退回收（低归属样品多为脱靶/失败库）。
6. **Q30 过滤（读质量，2026-08-14 新增）**：碱基质量 → 读质量按**概率法**换算 `readsQ = -10·log10(mean(10^(-Q_i/10)))`（平均误差率转 Q，**非对 Q 值直接平均**）；`readsQ < 阈值(默认30)` 的 read 记为 `qfiltered`，不进入归属与后续计数。
7. **多进程并行**（multiprocessing.Pool）。

**结果（Q30 过滤后）**：113 文件、175,854 reads，**Q30 过滤 42,539（24.2%）**；通过 reads（133,315）中归属 88.3%（both 83.4% + fonly 4.9%）。

```bash
cd scripts
python3 assign_reads.py --threads 16 --write-split   # 全量 + 写拆分 fastq（默认 Q30）
python3 assign_reads.py --min-q 30                   # 读质量阈值（概率法）
```

## 第 3 步　`count_cn.py` —— copy number 计数

**做什么**：对每个（样品×位点×SSR 区域×分量）数 reads 的重复单元数（CN），并给一致性指标。

**输入**：`data/assign/split/`、`data/annot/ssr_targets.bed`。
**输出**（`data/cn/`）：
| 文件 | 内容 |
|---|---|
| `cn_summary.tsv` | **主表**：样品×位点×target×分量：坐标/unit/ref_cn/方法/深度/主CN/**P/s1/s2**/次峰/判定/CN分布 |
| `cn_per_read.tsv` | 逐 read 明细（13.3 万行） |
| `cn_summary_stats.tsv` | 每样品：位数点(深度≥5)、平均P、总深度 |

**用到的策略**：
1. **侧翼锚定**：SSR 区域取参考 22bp 左/右翼作锚，read 中 edlib 找左翼（≤2 错配）定位 SSR 起点；右翼定位终点。左翼没命中的 read 不计（多为伪影/侧翼差异）。
2. **双方法自动切换**（核心）：
   - **长度法（len，默认）**：`CN = round(侧翼间距离 / 基序长)`。鲁棒于重复区内单碱基错误（如 (AGGT)7 中间插 1bp，run 法会数成 3，长度法正确给 7）。
   - **运行法（run）**：窗口内最长纯运行拷贝数（基序全部旋转）。用于**真复合位点**（PM25 CT+AC 按分量）。
   - 自动切换：len/run 众数差 >2 且 run≈ref_cn 时切 run（PM06 型）；**断裂简单重复**（曾 PM05/11）由 `classify_region` 归为简单 → 长度法。
3. **复合重复分解**（`decompose_ssr`）：一个区域内多基序（PM25 CT+AC）拆成各分量分别计数。
4. **多靶点分别锚定**：target 1/2/3 各自取侧翼计数，互不干扰。
5. **一致性指标**：主等位支持率 **P**（众数 CN 的 reads 占比，P≥60% ✅ / 40-60% ⚠️ / <40% ❌）、±1 重复率 s1（stutter 程度）、次峰 second_cn/second_pct（**杂合双峰检测**）。
6. **最低深度过滤（`--min-depth`，默认 10）**：每分量计数 reads 数（depth）低于阈值的分量**不写入输出**（summary + per_read 都跳过）——避免深度 1 的不可靠测量进入下游；阈值可调（`--min-depth 2` 保留弱测量）。
7. **多进程并行**（每样品一个 worker）。

**结果**（2026-08-14，Q30 过滤 + min-depth 10）：108 样品、49 区域、2,737 行、132,882 条 read（每分量 depth≥10）；**73.2% 测量 P≥60%**；35 个有数据位点中 27 个中位 P≥60%（多数≥90%）。收敛差的多为长纯重复位点（PM22/09/04/05，stutter）。
⚠️ min-depth 10 下 PM02/03/11/35/40 整位点无数据、PM06/09/10/17/21/33 大幅减少（深度不足）。**PM35 为全库无 reads（引物有效但扩增子未出现在文库，需排查建库）**。

```bash
cd scripts
python3 count_cn.py --threads 16 --min-depth 10   # 全量（每分量 depth≥10）
python3 count_cn.py --only barcode201-0            # 单样品调试
```

## 第 4 步　`bridge_cn2bp.py` —— CN→片段长度(bp)→国标Bin + 附录B验证

**做什么**：把平台的 CN 换算成 CE 测的片段长度（bp），映射到国标 Bin；用附录 B 的参照样品等位基因验证换算正确性。

**输入**：`cn_summary.tsv`、`gb_primers.tsv`、`ssr_targets.bed`、拆分 fastq、国标 md。
**输出**（`data/bridge/`）：
| 文件 | 内容 |
|---|---|
| `fragment_summary.tsv` | 样品×位点：reads实测bp / CN法bp / diff / GB范围 / 是否在范围内 |
| `gb_sites.tsv` | 修复后的 GB 引物结合位点坐标 |
| `validation.tsv` | 每位置：参考片段/附录B范围/两法一致性/等位基因网格命中 |

**用到的策略**：
1. **两套独立换算（相互验证，核心）**：
   - **reads 实测法（主）**：在每条 read 里用 GB-F/GB-R 结合位点实际序列（Sanger 验证）作锚，量**物理片段长度** = 测序结果里的 CE 片段。对嵌套位点（GB 引物在新引物扩增子内）有效，绕开参考坐标误差。
   - **CN 法（交叉验证）**：`fragment = flanking + Σ(GB扩增子内所有SSR的 CN×unit)`，其中 flanking = GB扩增子长 − Σ(ref_cn×unit)。多靶点/复合位点所有分量求和。
2. **GB 位点坐标修复**：docx 标注不完整的位点（PM05/15/27 等）用标准全长引物在参考中重定位；全部用"参考片段 ∈ 附录B 范围"自检。
3. **三重建验证**：
   - 验证 1（参考片段）：40 位点参考片段 ∈ 附录B 范围。
   - 验证 2（方法一致）：reads 实测片段 ≈ CN 法片段（两法独立，一致则换算正确）——样品级 |diff|≤3bp。
   - 验证 3（等位基因网格）：各样品片段应落在附录B 等位基因网格上（间距=基序长整数倍）。
4. **多进程并行**。

**结果**（2026-08-14，Q30 过滤 + min-depth 10）：2,061 (样品×位点) 有 reads 实测片段；**CN↔read 一致 86.2%**（只统计有真实 CN 数据的比较；PM27/31/36 精确命中国标等位基因 272/263/202bp）。

```bash
cd scripts
python3 bridge_cn2bp.py --threads 16
```

## 当前结论（摘要）

- **准**：约 3/4 位点（35 个有数据位点中 27 个）reads 高度收敛（中位 P≥60%，多数≥90%），CN→bp 换算被 86.2% 两法一致率支持 → 这些位点可替代 CE。
- **限制**：约 1/4 长纯重复位点（PM22/09/04/05 等）stutter 使单值 CN 不可靠，需报告 CN 分布或 CE 对照；PM11/13/18/32 的 bridge 锚特异性差；PM13 是高变 A 富集区；**PM35 全库无数据（建库问题）**。
- **下一步**：CE 对照数据（最硬真值）→ 长重复位点校准 → 品种真实性/身份鉴定演练。
