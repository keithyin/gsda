# 09　SSR Copy Number 一致性试点报告（reads 一致性口径）

> **目的**：验证"从 reads 数 copy number + 量化一致性"的方法可行，并给出**第一手结果**——平台测的 SSR copy number，reads 之间到底收不收敛。
> **口径**：判断"准不准"先看 reads 一致性（主等位支持率 P、±1 重复率 s、主峰清晰度），不依赖外部真值。
> **试点范围**：4 个样品（barcode201/202/203/206）× 各 20-25 个位点。
> **脚本与原始结果**：`scripts/cn_pilot.py`、`scripts/cn_pilot_结果.txt`。

---

## 1. 方法（一句话）

对每个位点：从参考序列定位 SSR 靶点 → 取 SSR 区**两侧各 22bp 稳定侧翼**作锚 → 在每条 read 中找两翼（精确匹配）→ 确认该 read 属于该位点 → 数两翼之间 SSR 区的**重复单元数（copy number）**。

对每个（样品 × 位点）统计所有 reads 的 copy number 分布，得到：

| 指标 | 含义 |
|---|---|
| 深度 | 归属到该位点的 reads 数 |
| 主 CN | copy number 的众数 |
| **主等位支持率 P** | 众数 CN 的 reads 占比（越高越"准"/越收敛） |
| **±1 重复率 s** | stutter（滑移）占比 |
| **≥±2 重复率** | 明显偏离主等位占比 |

## 3. 关键发现

### 发现 1：方法可行，一半 reads 可归属并数出 CN
- 每样品约 50% 的 reads 能通过两翼锚定归属到具体位点（其余未归属，需后续改进归属率——见第 4 节）。
- 归属到的 reads 能稳定数出 copy number 分布。

### 发现 2：多数位点 reads 高度收敛（P ≥ 80%）
- 短重复 / 3-4bp 单元位点（PM23 AGGT、PM20 TTTG、PM26 GCG、PM28 CTG、PM34 TG、PM39 TGG、PM19 TC、PM16 GTT 等）**P 普遍 82%~100%** → copy number 明确、可信。

### 发现 3：长纯重复位点系统性收敛差
- **PM22（(CT)×23，46bp 纯重复）在 4 个样品中全部 ❌（P 30%~39%）**——长纯重复位点 stutter 严重，reads 的 CN 从 ~10 到 ~40 离散。
- PM25（CT×9）不稳定：样品 2 P=90.6%✅ 但样品 1 P=41.4%⚠️。

### 发现 4：个别样品×位点收敛差，可能为杂合
- 样品 6 的 PM04（P=20.8%）、PM09（P=33.3%）；样品 2 的 PM05（P=36.4%）——低 P 但非系统性（其他样品正常或偏高），**可能该样品在这些位点是杂合/多等位**，而非测不准。需结合双峰判断。

---

## 4. 局限与下一步

| 局限 | 说明 | 改进 |
|---|---|---|
| 归属率 ~50% | 两翼精确匹配漏掉含测序误差/接头/短 read | 允许 ±1~2 错配、去掉接头后重试；或用完整参考映射（04 第3步） |
| SSR 靶点识别可能偏差 | 用"最长 2-6bp 串联重复"近似真实靶点（docx 红色标注才是权威） | 从 docx 颜色标注提取真实靶点，或与国标附录 B 核对 |
| 未区分"杂合 vs 测不准" | 低 P 可能是杂合位点（两等位各 ~50%）而非误差 | 加"双峰检测"：两主峰各 ≥40% 判为杂合 |
| 试点样品少 | 4 样品 × 20-25 位点 | 扩展到全量 96 样品 × 40 位点 |

---

## 5. 结论（试点层面）

> **平台测 SSR copy number，多数位点 reads 高度收敛（P≥80%，可信）；但长纯重复位点（如 PM22）系统性 stutter 严重，copy number 不可靠；个别样品×位点疑似杂合需单独判断。** 这为"平台测 CN 准不准"给出了第一手、可量化的回答。

下一步建议：**把试点扩展到全量 96 样品 × 40 位点**，产出每位点/每样品的一致性总表（含杂合标记），并据此给出"哪些位点平台能测准、哪些不能、误差多大"的完整结论。
