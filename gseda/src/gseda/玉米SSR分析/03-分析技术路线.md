# 03　分析技术路线（平台数据 → 国标可比分型）

> 本文档回答一个核心问题：**平台给出的"序列"怎么换算成国标能判定的"片段大小 + 等位基因"。**
> 三座桥（方案 A/B/C）如何选择、如何组合，以及分析前要准备好哪些输入。

---

## 1. 目标

把 96 个样品的 PacBio HiFi 原始 reads，分析成**国标 GB/T 39914-2021 可比的分型结果**，进而按国标规则判定：

- 每个样品 × 40 位点 → 等位基因（片段大小 bp，可落入附录 B 的 Bin）
- 真实性验证：差异位点数 ≤ 2
- 纯度测定：异常个体比例 + GB/T 3543.1 容差

---

## 3. 三座桥（核心）：怎么把"序列"变成"国标长度"

### 桥 A：模拟国标原始引物扩增子（主方案，推荐）

**原理**：国标的所有 Bin / 参照样品数值，都基于"表 1 原始引物扩增出的片段"（126~430 bp）。平台扩增子（450~550 bp）与原始扩增子**同一位点、不同边界**。只要知道原始引物在序列中的**结合位置**，就能把平台序列"裁"成国标扩增子，量出"国标会读到的长度"。

```
平台扩增子（~500bp，来自HiFi read）:
┌───────────────────────────────────────────────┐
│ 新引物F2  [━━━ 侧翼 ━━━ SSR重复区 ━━━ 侧翼 ━━━] 新引物R2 │
│            ↑原始引物F结合位点     原始引物R结合位点↑       │
└────────────┴──────────────────────┴────────────┘
          裁出这段 ────►  长度(L)  就是"国标CE当量长度"
```

**实现要点**：
1. 每个位点需要**原始引物（表 1）的结合坐标**。来源二选一：
   - 从平台参考序列的 docx **颜色标注**提取（黄色=原正向、绿色=原反向）——需用带格式解析 docx；
   - 若参考序列里没有原始引物（实测 40 位点中仅 7 个正反引物齐全），把原始引物序列 **mapping 到玉米参考基因组 B73** 确定坐标，再取对应坐标的参考序列。
2. 对每条 read：找到原始引物结合位置 → 取两引物之间的序列 → 计算长度 L（= 国标 CE 当量长度）。
3. 把 L 对照**附录 B 表 B.1 的 Bin**（如 PM01：320/322/325…），归入对应等位基因。

**优点**：与国标数字**直接可比**，报告可写"与标准样品比较差异位点数"。
**前提**：原始引物坐标可得；SSR 重复区外的侧翼在品种间稳定（一般成立）。

### 桥 B：重复单元计数（交叉验证 / 兜底）

**原理**：SSR 的本质差异是**重复单元数**（如 `GA` 重复几次）。直接从序列数重复次数，不依赖绝对长度。

```
GAGA GAGA GAGA GAGA GAGA GAGA  →  (GA)×6  →  等位基因代号 "6"
```

**用法**：
- 与桥 A 互相印证：桥 A 的长度差一个重复单元时，用重复数判定；
- 当参考序列缺失原始引物、或侧翼在品种间不稳定时，作为兜底方案（但需要自己建立"重复数 → 等位基因"的对应，不能直接引国标 Bin）。

### 桥 C：CE 对照校准（最强验证，条件允许才用）

**原理**：若同批样品用国标方法（CE）测过，就有了"真值"。用它来：
1. **校准**：建立"平台序列长度 → CE 片段大小"每个位点的偏移量（如 PM35 平台长度 +2 bp = CE 大小）；
2. **验证**：平台分型结果 vs CE 结果的一致性（一致率、差异位点是否吻合）。

**用法**：桥 C 不是独立路线，是给桥 A/B 的结果**做验收**。建议至少对部分样品（如已知品种、参照样品）做 CE 对照。

---

## 4. 方案选型建议

| 场景 | 推荐组合 |
|---|---|
| 有完整原始引物坐标 | 桥 A 为主，桥 B 校验；有条件加桥 C 验收 |
| 部分位点原始引物坐标缺失 | 该位点退回桥 B（重复数），其余用桥 A |
| 有 CE 对照 | 桥 A + 桥 C（校准 + 验收），最有说服力 |
| 无 CE 对照、坐标缺失多 | 桥 B 为主（需自建等位基因命名），报告注明"采用其他 SSR 引物，结果经重复单元计数表示" |

> **合规声明要点（国标 10.1.4/10.2.2）**：平台用了非国标引物 → 报告中必须**注明引物名称及序列**；若检测方式与国标电泳不同 → 建议在报告中说明"采用测序方法检测，结果与国标毛细管电泳经 XXX 方式校准/对应"。

## 5. 分析前要准备的输入

### 5.1 40 位点参考库（FASTA + 注释）

从 docx 提取 40 条参考序列（930~2413 bp），为每条记录：

```
>PM01 bnlg439w1 chr1.03
[参考序列...]
## 注解（每位置）:
# 位点: PM01  bnlg439w1
# SSR 重复基序: (重复单元，从 docx 红色靶点提取)
# 原始引物F结合位点: 位置 X..Y（序列）
# 原始引物R结合位点: 位置 X..Y（序列或反向互补）
# 新引物F1/R1、F2/R2 结合位点: 位置（用于界定平台扩增子）
# 国标Bin: 320,322,325,...(附录B)
# 参照样品片段: 郑单958 322/354 ...
```

### 5.2 原始引物坐标的两种获取方式

| 方式 | 做法 | 适用 |
|---|---|---|
| **解析 docx 颜色标注** | 用 python-docx 读取 docx 中黄/绿/青/紫/波浪/下划线字体，提取各引物序列及在参考序列中的位置 | 参考序列含原始引物时（实测仅 7/40 齐全） |
| **比对 B73 基因组定位** | 用原始引物序列（或含引物的参考片段）mapping 到玉米 B73 参考基因组（AGPv4/5），确定位点基因组坐标，再取基因组序列建参考 | 参考序列缺原始引物时 |

### 5.3 映射工具与参考（复用平台已有）

| 工具 | 用途 | 位置 |
|---|---|---|
| `edlib`（python） | 局部精确比对，read→位点、序列内找引物结合位点 | 已装 |
| `mappy`（minimap2） | 大批量 read 映射到参考 | 已装 |
| `pysam` | 读 BAM、统计覆盖 | 已装 |
| 平台 `asrtc` / `reads_quality_stats_hp_v3` | 已有 STR 分析，可参考其 MSA/质控思路 | `gseda/src/gseda/` |
