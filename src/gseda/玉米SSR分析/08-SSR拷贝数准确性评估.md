# 08　SSR Copy Number（重复单元数）准确性评估

> **这是本项目的核心关注点**：平台用 PacBio HiFi 测序测出的 SSR **copy number（串联重复单元数）准不准**。
> 国标 GB/T 39914-2021 是参考口径（copy number 决定片段大小，片段大小决定等位基因），但最终目标是**评估平台测 copy number 的能力**。
> 本文档定义：数据里有什么、怎么量化"准不准"、判定标准、需要什么。

---

## 1. 问题定义

### 1.1 什么是 SSR copy number

一个 SSR 位点 = 一段串联重复，如 `(GA)×6` = GA 重复 6 次。

```
GAGA GAGA GAGA GAGA GAGA GAGA   ← copy number = 6
```

**copy number 就是重复单元数 n**。它直接决定该位点的序列长度：
`片段长度 ≈ 左侧翼 + n × 单元长度 + 右侧翼`，也因此决定国标里的"片段大小 Bin"。

### 1.2 "准不准"是什么意思

平台从 HiFi reads 输出一个 consensus（含该位点的 SSR 区，即报出一个 copy number n̂）。"准不准"就是 **n̂ 与"真值 n" 的偏差**，以及**reads 之间对这个 n 的共识程度**。

两层含义：
1. **reads 内是否一致（收敛）**：几千条 reads 报的 copy number 是否集中在同一个值？还是有大量 ±1/±2 的 stutter？
2. **平台报值 vs 真值**：平台 consensus 的 n̂ 是否等于真值 n（参考序列 / Sanger / CE）？

---

## 2. 平台数据里有什么（可以直接用）

### 2.1 数据来源

| 数据 | 说明 | 对 CN 评估的作用 |
|---|---|---|
| 每样品原始 reads（fastq） | 每个位点几百~几千条 read | **直接精确数每条 read 的 copy number** |
| consensus.fasta | 平台把 reads 聚出的共识序列 | 平台报出的 copy number（n̂） |
| frequency_table | consensus 逐位置碱基深度/频率 | 量化 SSR 区每个位置的 reads 分歧 |
| **suspicious_sites** | SSR 区 indel/低一致位点明细 | **平台已算出的 copy number 变异分布** |
| 参考序列（docx） | Sanger 验证过的位点序列 | 真值之一（参考的 copy number） |
| ab1（Sanger 峰图） | 部分样品的 Sanger 结果 | 真值之一（如有） |

### 2.2 suspicious_sites 已经给出了什么（实测）

`suspicious_sites.txt` 的 `insert_seq` 列直接列出 SSR 区每个位置的 indel 分布：

```
# 实测例子1（某(GA)n位点，depth=212）：
位置142 G 主等位71.7%
  insert: GA:36条(=+1重复)  GAGA:19条(=+2重复)  GAGAGA:9条(=+3重复)  ...
  → 约 17% reads 多了 1 个 GA 重复，9% 多了 2 个，4% 多了 3 个

# 实测例子2（某(TC)n位点，depth=294）：
位置356 T 主等位62.6%
  insert: TC:33(+1) TCTC:21(+2) TCTCTC:12(+3) TCTCTCTC:9(+4)  ...
  → 37.4% reads 偏离主等位
```

**结论**：平台数据已能量化每个位点的 copy number 变异（主等位占比 + ±k 重复分布）。这正是"准不准"的第一手证据。

### 2.3 实测案例：从 reads 数 copy number（验证方法可行）

以 barcode201 样品的 (GA)n 位点为例（consensus 报 n̂=32）：

**方法**：SSR 区两侧取 ~23bp 稳定侧翼作为锚点 → 确认 read 确实属于该位点 → 数两翼之间 SSR 区的 GA 重复数。

```
reads 主等位 copy number = 32  （330 条属于该位点的 read 中占 19.1%）
平台 consensus 报 n̂ = 32  →  ✅ 一致
±1 重复 占 29.7%；≥±2 重复 占 51.2%
```

**关键发现**：
1. **平台 consensus 报值与 reads 主等位一致** → 该位点平台报的 copy number 是"reads 中最常见的值"，本身是准的。
2. **但长纯重复位点（此处 64bp 纯 GA）stutter 极高**：reads 的 CN 在 17~35 之间离散，≥±2 重复占一半以上。这意味着"单条 read 报的 CN"不可靠，只有靠大量 reads 投票得到的众数才有意义。
3. **方法前提**：数 copy number 必须先做位点归属（侧翼锚定），否则多位点混合 reads 会被数错（实测不锚定时会出现 CN=2 的假主等位）。

> 对"准不准"的意义：**短重复位点（如 CN 5~15）预计 stutter 低、易测准；长纯重复位点（CN 大或同聚物）stutter 高，需要大量 reads 投票 + 明确报告不确定性。**

## 3. 评估框架（怎么量化"准不准"）

### 3.1 指标定义

对每个（样品 × 位点）定义：

| 指标 | 定义 | 含义 |
|---|---|---|
| **n̂（平台报值）** | consensus SSR 区重复数 | 平台输出 |
| **深度 depth** | 该位点 reads 数 | 支撑强度 |
| **主等位支持率 P** | 众数 copy number 的 reads 占比 | 越高越"准"（收敛） |
| **±1 重复率 s** | 恰好差 1 个重复单元的 reads 占比 | stutter/滑移比例 |
| **≥±2 重复率** | 差 2 个以上重复的 reads 占比 | 异常/杂合/测序错误 |
| **多峰性** | copy number 分布是否有两个主峰 | 杂合（两等位）vs 单一+stutter |

**判定逻辑**：
- 若分布**单峰且 P 高**（如 ≥85%）→ copy number 明确，平台报值可信；
- 若 **s 高**（±1 重复多）→ 平台报值可能是"众数"，但存在系统性 stutter，需说明不确定性；
- 若 **双峰**（两个等位都 ~50%）→ 是杂合位点（两个 copy number），不是测不准；
- 若分布**散乱**（无主峰）→ 该位点 copy number 不可靠（可能纯合但测序错误，或异质）。

### 3.2 与真值比对（判定"准不准"的硬标准）

> **本项目判定口径（已确认）**：**先主要依据 reads 的一致性**来评估 copy number 准不准（不依赖外部真值）。外部真值（参考/Sanger/CE）作为**辅助验证与校准**，有条件再补。

| 真值来源 | 做法 | 可得性 |
|---|---|---|
| **reads 一致性（主口径）** | reads 是否收敛到同一 copy number：主等位支持率 P、±1 重复率 s、主峰是否清晰 | ✅ 数据已有，可立即评估 |
| **参考序列**（docx） | 参考中 SSR 区重复数 = n_ref；比较平台 n̂ vs n_ref | ✅ 已有 |
| **Sanger ab1** | 从 Sanger 序列/峰图数出 n_sanger | 🔶 部分有 |
| **CE 片段大小** | 片段大小 → (大小 - 侧翼)/单元长 = n_ce | 🔶 需客户提供 |
| **技术重复** | 同一 DNA 样品重测，两次 n̂ 一致性 | 🔶 需确认是否有 |

**误差定义**：`Δ = n̂ − n_true`。统计每位点的 Δ 分布：
- 若 Δ 集中在 0（±0.5）→ 平台准；
- 若系统性偏移（如 Δ 恒为 +2）→ 平台有系统偏差（可能是 HiFi 在重复区的插入偏好），需要校正；
- 若 Δ 离散大 → 平台在该位点不可靠。

### 3.3 对国标片段大小的影响（桥接）

片段长度 ≈ 侧翼长度 + n̂ × 单元长。
- 单元 2bp（如 GA）：Δ=1 重复 → 片段差 2bp；
- 国标 Bin 内取整允许 ±1bp（国标 7.5.2.1：峰落入 Bin 内直接读取，可整体平移）。
- 因此 **Δ=±1 重复在 2bp 单元位点上刚好处于国标可接受的临界**；评估时要把"copy number 误差 → 片段大小误差 → 是否超 Bin"串起来。

## 4. 分析步骤（执行方案）

### 第 1 步：精确定位每个位点的 SSR 靶点与重复基序
- 从 docx 参考序列（红色靶点标注）或 TRF 算法识别每个位点的重复单元和参考 copy number（n_ref）。

### 第 2 步：每样品×位点 从 reads 数 copy number
- 把 read 比对到位点参考 → 定位 read 中 SSR 区 → 数重复数 → 得到该位点的 copy number 分布。

### 第 3 步：汇总指标表
```
样品 | 位点 | 基序 | n_ref | 平台n̂ | depth | 主等位支持率P | ±1率s | ≥±2率 | 双峰? | Δ=n̂-n_ref
```

### 第 4 步：与真值比对 + 误差统计
- 全局：Δ 的分布、每位点 Δ 的均值/标准差、系统性偏移检验。
- 若客户提供 CE：平台 n̂ vs n_ce 一致性。

### 第 5 步：结论与报告
- 哪些位点/样品 copy number 测得准、哪些不准、误差多大、对国标片段大小判定的影响。
- 是否需要校正因子（如系统偏移）。

---

## 5. 判定标准（reads 一致性口径，建议阈值，需数据校准）

> **主口径**：不看外部真值，只看 reads 是否收敛到同一 copy number。

| 判定 | 阈值（建议） |
|---|---|
| **收敛良好（可信）** | 主等位支持率 P ≥ 80% 且 ≥±2 重复占比 < 10% |
| **存在 stutter 但可用** | 80% > P ≥ 60%，或 ±1 重复率高但主峰清晰；报告注明 ±1 重复率 |
| **收敛差（不可靠）** | P < 60%，或分布无主峰 / 散乱 |
| **疑似杂合** | 两个主峰各 ~40~60%（不是测不准，是双等位基因） |

> 注：P 与位点特征相关——**短重复位点（CN 5~15、2~3bp 单元）预期 P 高；长纯重复位点（CN 大、同聚物）P 会明显降低**（实测 (GA)32 位点 P≈19%）。阈值最终应由平台/客户认可后定，也可按位点特征分组设阈值。

## 6. 需要客户/平台确认（聚焦 copy number）

| # | 事项 | 影响 |
|---|---|---|
| 1 | ✅ **已确认**：判定口径 = **reads 一致性**（主）；参考/Sanger/CE 为辅助 | 可立即开始评估 |
| 2 | 每样品属性（独立个体/品种）——决定同品种多样品的一致性验证 | 辅助验证 |
| 3 | 是否有重复测序的同一 DNA 样品（技术重复） | 重复性评估 |
| 4 | 阈值是否按位点特征分组设定 | 判定标准细化 |

---

## 7. 一句话总结

> **平台数据里 copy number 的不确定性是可直接量化的**。"准不准"（reads 一致性口径）= reads 是否收敛到同一 copy number：主等位支持率 P（越高越准）+ ±1 重复率 s（stutter 比例）+ 是否有清晰主峰。评估产出：每位点/每样品的收敛指标表 + 位点特征（短/长重复）对准确性的影响结论。
