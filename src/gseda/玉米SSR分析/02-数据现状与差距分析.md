## 2. 平台现在"输出"什么

平台对每样品的产出（`barcodes_reads_cons_gen_amplicon/Consensus/`）：

1. **consensus.fasta**：1-3 条共识序列（`>Clust_0.1.1|len:560|num:212|ratio:0.07|complete:Yes|sus:4`），字段含长度、簇内 read 数、占比、完整性、可疑位点数。
2. **frequency_table.txt**：consensus 每个位置各碱基深度与频率、质量、可疑类型（Homo/Indel 等）。
3. **suspicious_sites.txt**：低一致位点明细（如 Indel：`GA:36;GAGA:19...`）。
4. **QC png**、**sort.bam**、**ab1**（Sanger 峰图）。

**一句话总结平台输出的特点**：平台做的是"把每样品里 reads 最多的 1-3 个位点聚成 consensus + 质控"，**并不是按国标 40 位点做的分型结果**。

## 3. 与国标要求的逐项对照

| 国标要求 | 平台现状 | 差距 / 结论 |
|---|---|---|
| **位点体系**：40 对核心引物 PM01~40 | 平台位点命名与国标**完全一致**（PM01=bnlg439w1…PM40=umc2163w3），参考序列含全部 40 位点 | ✅ 位点一致，可直接对应 |
| **引物**：表 1 原始引物（扩增子 126~430 bp） | 平台用**自行设计的 450~550 bp 新引物**（每位置两对 F1/F2） | ⚠️ 位点相同、扩增子不同 → 片段大小基准不同，**不能直接比**（需搭桥，见 03） |
| **检测平台**：毛细管电泳等 | PacBio HiFi 测序 | ⚠️ 平台不同 → 需论证等价或经换算可比 |
| **样品数量**：真实性种子 ≥200g/500粒；纯度 ≥96×2 粒 | 96 个样品（barcode） | 🔶 若 96=96 粒独立单粒 → 数量接近纯度要求；**需确认样品属性** |
| **单粒独立检测（纯度）** | 每样品一个 barcode | 🔶 需确认每 barcode = 1 个单粒来源，还是混合样 |
| **全 40 位点分型** | 平台 consensus 仅覆盖每样品 1-3 个位点 | ❌ **核心差距**：现有输出拿不到 40 位点 → 必须回到原始 fastq 重新分型 |
| **等位基因表示**：片段大小 bp + Bin | 平台无等位基因/片段大小输出 | ❌ 需从序列计算 |
| **差异位点统计**（≤2 判定） | 无 | ❌ 需分析后统计 |
| **标准样品/参照样品** | 未提供 | 🔶 需确认比对对象 |
| **CE 对照** | 未提供 | 🔶 有则是最硬验证 |
| **报告（第 10 章格式）** | 无 | ❌ 需按模板产出 |

## 4. 差距总结（三条核心差距）

### 差距 1：平台 consensus 覆盖不全（技术路线根本原因）
> 平台现成输出每样品只有 1-3 个位点的 consensus。**要做 40 位点国标评估，必须从 `barcodes_reads_fastq_amplicon/` 的原始 reads 出发，重新做"样品 × 位点"的完整分型。**

### 差距 2：片段大小基准不同（换算桥梁）
> 国标判定基于"原始引物扩增子长度 + Bin"；平台基于"新引物扩增子序列"。需要把平台序列换算成国标可比的长度（方案 A 模拟原始引物扩增子、B 数重复、C CE 校准）。

### 差距 3：比对对象缺失
> 真实性判定需要"标准样品/参照样品"的指纹，纯度判定需要"品种正常个体"的定义。目前没有提供，是**待确认项**。
