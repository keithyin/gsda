## 🗺 项目一句话地图

```
平台HiFi数据(96样品×40位点) ──► 数每条read的SSR重复数(copy number)
      │
      ▼
量化"准不准"：① reads是否收敛(主等位支持率P/±1重复率s)
             ② 平台报值n̂ vs 真值n(参考/Sanger/CE) 的误差Δ
      │
      ▼
对标国标：copy number → 片段大小 → Bin → 能否用于真实性/纯度判定
```

## 🔑 核心结论（记住这些就够了）

1. **平台数据里 copy number 的不确定性可直接量化**：`suspicious_sites` 已给出每个位点 SSR 区的主等位占比与 ±k 重复分布（实测主等位支持率 62%~72%，其余为 ±1~±4 重复的 stutter）。
2. **位点一致**：平台 PM01~PM40 与国标核心引物完全一致；但引物不同（450-550bp vs 126-430bp），需桥 A 换算对标国标 Bin。
3. **平台 consensus 覆盖不全**：每样品只有 1-3 个位点的 consensus，全面评估需回到原始 reads 重新数 copy number。

## ⚠️ 阻塞性待确认项（见 07 / 08 详述）

- **CE 对照数据**（如有）——判定 copy number 准不准的最硬真值
- 接受"reads 一致性 + 参考序列/Sanger"作为真值的口径
- 每样品属性（独立个体？品种？）、是否有技术重复
