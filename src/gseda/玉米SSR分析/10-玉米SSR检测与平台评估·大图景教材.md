在做任何细节之前，先看整个项目的一张总图。这张图是全文的地图，后面每一章都是地图上的一个站点。

【现实需求】                    【检测方法】                  【判定结果】
┌────────────┐    ┌──────────────────────────┐   ┌──────────────────────┐

再具体一点，把"方法2 平台法"这一支拆开：

```
96个样品(每个一个barcode)
      │
      ▼
PacBio HiFi 测序机  ──►  每样品得到一批"reads"（DNA片段序列）
      │
      ▼
从 reads 中找出 40 个 SSR 位点各自的序列（我们这一步要做的分析）
      │
      ▼
读出每个位点的"等位基因"（相当于品种在这40个点的"指纹"）
      │
      ▼
和国标要求的判定规则比对  ──►  判定：样品符不符合国标要求
```

**这份教材要做的，就是让你把上图每一站都看懂。**

如果你只想记住三个词，请记住：

1. **SSR**：玉米基因组里的一类"重复小段"，不同品种重复次数不同 → 可以当"身份指纹"用。
2. **国标方法**：用 PCR + 电泳，读出每个位点的**片段长度**（多少 bp）。
3. **平台方法**：用 HiFi 测序，读出每个位点的**DNA 序列**。两者位点相同，但"读出的东西"不同，需要一个**换算桥梁**——这是本项目最核心的技术难点（第 6 章）。

## 第 1 章　为什么要鉴定玉米品种

### 1.1 现实问题

种子的世界里有一个古老的难题：**你怎么知道这一袋玉米种子，真的是包装袋上写的那个品种？**

假种子、套牌种子（拿普通品种冒充名牌品种）、混杂种子（一个批次里混进了别的品种）都会让农民蒙受损失。所以农业上有专门的**品种检测**，目的就两个：

| 检测类型 | 回答的问题 | 打个比方 |
|---|---|---|
| **真实性验证** | "这个样品，是不是它标称的那个品种？"（验明正身） | 查身份证：这人是张三吗？ |
| **真实性身份鉴定** | "这个样品，到底是哪个品种？"（不知道是谁，去比对数据库） | 查指纹库：这人是谁？ |
| **纯度测定** | "这一批种子，是不是同一个品种、够不够纯？" | 检查一批货：是不是都合格？ |

本项目要评估的，就是**平台用测序方法得出的 SSR 结果，能否用来做上面这三种检测，并且符合国标的要求**。

### 1.2 一句话总结本章

> 品种检测 = 给玉米做"指纹鉴定"。国标规定了怎么采指纹（40 个 SSR 位点）和怎么比对（真实性 ≤2 个位点不同即成立；纯度看异常个体比例）。

## 第 2 章　从零讲生物基础

这一章给没有任何生物背景的你打地基。只讲本项目需要的几个概念。

### 2.1 DNA：生命的遗传说明书

每个生物的细胞里都有一本"说明书"，写着怎么长成这个生物。这本说明书就是 **DNA（脱氧核糖核酸）**。

DNA 由四个"字母"串成一条很长的链：**A、T、C、G**。你可以把 DNA 想象成一段由四个字母写成的超长文本。玉米的这本"说明书"大约有 **23 亿个字母**（碱基）。

- **碱基** = 一个字母（A 或 T 或 C 或 G）
- **碱基对（bp, base pair）** = 两个字母成对（DNA 是双链，A 对 T，C 对 G）。测序报告里说的"320 bp"就是"320 个碱基对"，相当于一段 320 个字母长的文本片段。
- **基因** = 说明书里的一段有特定功能的文字（比如"决定叶子形状"）。
- **基因组** = 整本说明书（全部 DNA）。

### 2.2 染色体：说明书的分册

这么大的文本不能一团乱放，它是分成一本本"分册"的，每一册叫一条**染色体**。

玉米有 **10 对染色体**（20 条）。为什么是"对"？因为玉米的每个细胞里，每一册说明书都有**两份**——一份来自爸爸（父本），一份来自妈妈（母本）。这两份内容高度相似，但可能在某些位置有一点点差别。

### 2.3 等位基因：同一位置的两种"版本"

想象你有两册《玉米说明书》，一册来自爸爸、一册来自妈妈，翻到第 3 册第 5 页，爸爸的写着"红色"、妈妈的写着"白色"。这个"同一位置、可能不同版本"的东西，就叫**等位基因（allele）**。

- 两个版本相同 → **纯合**（homozygous）
- 两个版本不同 → **杂合**（heterozygous）

打个比方：你和你的孪生兄弟各自有一本作业本，同一道题"1+1="——
- 两本都写"2" → 纯合
- 一本写"2"、一本写"2"涂改成"3" → 杂合

### 2.4 为什么不同品种的 DNA 不一样

不同玉米品种的"说明书"绝大部分相同（毕竟是同一个物种），但个别位置有差异：有的字母不同，有的地方多一段、少一段。这些差异就是品种的"身份特征"。

打个比方：同一本书的不同印刷版，正文几乎一样，但有些字印错了、有些段落重复了一遍。**SSR 就是那种"重复段落"的差异。**

### 2.5 本章小结

- DNA = 由 ATGC 四字母写成的遗传说明书（玉米 23 亿字母，分 20 条/10 对染色体）。
- 每对染色体有两份（父本+母本），同一位置的两个版本叫**等位基因**。
- 版本相同 = **纯合**；不同 = **杂合**。
- 不同品种之间 DNA 有差异 → 可以用这些差异鉴定品种。
- **bp = 碱基对 = 长度单位**，后面会一直用到。

## 第 3 章　SSR 是什么，为什么用它

### 3.1 SSR = 一段"重复的小段"

**SSR（Simple Sequence Repeat，简单序列重复）**，也叫**微卫星（microsatellite）**，是基因组里一种特殊的段落：

```
染色体上的一段 DNA：
...ACGT GAGA GAGA GAGA GAGA GAGA GAGA GAGA CGTA...
              └──── 一段 (GA) 重复了 7 次 ────┘
```

也就是说，SSR 是一段**由同一个"小单元"连续重复多次**的 DNA。这个小单元通常是 1~6 个字母，比如 `GA`、`CT`、`AC` 等。

### 3.2 为什么 SSR 能区分品种

关键在于：**不同品种在同一位置，这个"小单元"重复的次数往往不同。**

```
品种甲：...GAGA GAGA GAGA GAGA ...   ← (GA) 重复 4 次，这一段短
品种乙：...GAGA GAGA GAGA GAGA GAGA GAGA ...   ← (GA) 重复 6 次，这一段长
```

同样是这个位点，两个品种的 DNA 长度不一样。**只要测出这段重复序列有多长（或重复了几次），就能把品种区分开。** 这就像"指纹"里的一个特征点。

而且 SSR 在玉米基因组里分布广泛、数量多，全基因组有几千上万个，可以挑出一批"特征点"组合成一套稳定的"身份证号"。

### 3.3 SSR 的四大优点（为什么国标选它）

| 优点 | 解释 |
|---|---|
| **多态性高** | 不同品种差异明显，很容易区分 |
| **共显性** | 杂合时父本和母本的版本**都能看到**（两个"指纹"同时显示）→ 信息量大 |
| **稳定可重复** | 只要方法标准，不同实验室结果一致 → 适合定国标 |
| **成本低、成熟** | 传统 PCR+电泳就能测，全国种子检测机构都用 |

### 3.4 玉米的"40 个指纹点"：核心 SSR 位点

国标 GB/T 39914-2021 从玉米基因组里选了 **40 个 SSR 位点**作为标准指纹点，编号 **PM01 ~ PM40**，均匀分布在 10 条染色体上（每条染色体约 4 个）。编号和品种鉴定平台完全一致（比如 PM01 对应基因位点 `bnlg439w1`，PM35 对应 `bnlg2235y5`）。

40 个位点分成两组：

- **I 组：PM01 ~ PM20**（20 个）
- **II 组：PM21 ~ PM40**（20 个）

这样分组是为了"先测一半，拿不准再测另一半"，节省成本（详见第 8 章判定规则）。

### 3.5 本章小结

> SSR = 基因组里"小单元重复"的段落；不同品种重复次数不同 → 长度不同 → 可以当指纹点。国标选了 40 个这样的位点（PM01~PM40），分 I、II 两组。

## 第 4 章　国标方法怎么做（传统的"长度检测"）

国标规定的检测是**湿实验**（在实验室用化学/物理方法做），流程如下：

```
取样 → 提取DNA → PCR扩增 → 电泳分离 → 判读（读出片段大小 bp）
```

下面一步步用类比讲清楚。

### 4.1 取样：拿到玉米材料

从送检样品里取代表性子粒/叶片等。国标对数量有要求（如真实性：种子 ≥200 g 或 ≥500 粒；纯度：杂交种要 ≥96×2 粒单粒检测），第 8 章会讲。

### 4.2 提取 DNA：把"说明书"拆出来

把玉米组织的细胞破开，把里面的 DNA 纯化出来。国标要求 DNA 质量好（OD260/280 在 1.8~2.0），保证后面 PCR 能成功。可以理解为：**从书本（细胞）里把正文（DNA）干净地抽出来**。

### 4.3 PCR 扩增：复印机

PCR（聚合酶链式反应）是"DNA 复印机"。你关心的 40 个 SSR 位点只占整个基因组极小的一部分，直接测大海捞针，所以要用 PCR 把它们**单独复制放大几百万份**。

关键工具是**引物（primer）**：两段短的 DNA，像"书签"一样贴在目标片段的两头，PCR 就从这两头开始复制中间那段。

```
引物F ──▶  ┌──────────────────────────────┐  ◀── 引物R
          │   [SSR重复区]  ← 我们关心的就是这段  │
          └──────────────────────────────┘
    └──────── 引物之间的这段 = "扩增子"（amplicon） ────────┘
```

国标用 40 对**原始引物**（附录表 1），扩增出来的片段长度在 **126~430 bp** 之间（每个位点不同，附录 B 有每个位点的范围，比如 PM01 是 320~368 bp）。

### 4.4 电泳：按大小排队

PCR 产物是一堆长度略有差别的 DNA 片段。**电泳（electrophoresis）**就是让它们在一个电场里跑：DNA 带负电，会向正极跑；跑得快的（短的）在前面，跑得慢的（长的）在后面，于是**按长短排成一队**。

国标最推荐的平台是**毛细管电泳（CE，Capillary Electrophoresis）**，精度高达 **1 bp**。它配一个"分子量内标"（已知长度的参照尺子），就能精确读出每个片段的长度：

```
信号强度
  │
  │      ╱╲
  │     ╱  ╲        ╱╲
  │    ╱    ╲      ╱  ╲
  │───╱──────╲────╱────╲────  →  片段大小（bp）
  │        "320bp"   "350bp"
```

每个"峰"（peak）就是一个片段。**纯合位点 = 一个峰（两个版本一样长）；杂合位点 = 两个峰（两个版本长度不同）。**

### 4.5 判读：读出等位基因（片段大小）

这一步把"峰"转成"等位基因"。国标定义了 **Bin**（片段大小区间）：

> **Bin** = 一个位点上、代表某一个等位基因的片段大小区间。比如 PM01 位点上，"320 bp"、"322 bp"、"325 bp"……每个就是一个等位基因的 Bin。

因为电泳有测量误差，片段大小落在同一个 Bin 里就视为同一个等位基因。例如某样品在 PM01 位点测出 320 和 350 两个峰 → 记作 `320/350`（杂合，两个等位基因）。国标的数据记录格式是：纯合 `X/X`、杂合 `X/Y`（小在前）、缺失 `0/0`。

### 4.6 本章小结

```
国标流程：取样 → 提DNA → PCR(40个位点分别放大) → 毛细管电泳 → 读出片段大小(bp) → 对照Bin判定等位基因
```

国标方法最终产出：**每个样品在每个位点的一个或两个"片段大小"**（如 `320/350`）。这套大小就是品种的"指纹数值"。

## 第 5 章　平台方法怎么做（测序）

### 5.1 平台思路：用测序替代电泳

平台的做法是：**不测"长度"，而是直接把 40 个位点的 DNA 序列全部读出来。**

这样做的优势：测序能读出**每个字母**，比电泳"量长度"信息量大得多、也能区分更细微的差异。

### 5.2 平台数据是怎么产生的

你手上的 PacBio CCS HiFi 数据，产生过程如下：

```
1. 对每个样品做多重 PCR：
   把 40 个位点（PM01~PM40）的引物放进一管，一次扩增出 40 段扩增子
        │
2. 给每个样品贴上"标签"（barcode）：
   96 个样品各用 1 个专属 barcode（一段已知的小 DNA 序列），
   之后几十个样品的产物可以混在一起上机，再按 barcode 分开
        │
3. PacBio HiFi 测序：
   仪器读出每一条 DNA 片段上每个位置的字母（A/T/C/G），
   生成"reads"（读段）——每条 read 就是一段 DNA 的完整字母序列
        │
4. 拆 barcode：
   按 barcode 把 reads 分回各自样品 → 每个样品一份 fastq 文件
```

> **Fastq 文件** = 测序结果的通用存储格式：每 4 行为一条 read——第 1 行名字、第 2 行 DNA 序列（ATCG…）、第 3 行"+"、第 4 行每个位置的质量分数。

因为平台为了配合测序，**重新设计了引物**（把扩增子做到 **450~550 bp**，比国标原始引物的 126~430 bp 更长），每条 read 大约就是 450~550 bp（实测中位数约 620 bp，含接头）。

### 5.3 读一遍你手上的真实数据

实测这批数据（`20260702_251201Y0001_Run0003/Group_0/`）：

- **96 个样品**（编号 `MP19548-1-1` ~ `-1-96`），每个样品一个 barcode，映射表在 `Group_0_Summary_None.csv`。
- 每个样品有约 **2000~4000 条 reads**。
- 每个样品是**多重扩增子**：一管里同时扩了多个位点，所以一个样品的 reads 会同时包含多个位点（实测单样品含 14~20+ 个位点的 reads）。
- 每条 read 长度集中在 400~700 bp（对应扩增子+接头），尾部有一些 1~10 kb 的长读（可能是接头串联/污染，分析时要过滤）。

### 5.4 测序 vs 电泳：本质区别（非常重要）

| | 国标 CE | 平台 HiFi 测序 |
|---|---|---|
| 读到的信息 | **片段长度**（多少 bp） | **完整 DNA 序列**（每个字母） |
| 精度 | 1 bp | 逐字母（可精确到 1 个碱基） |
| 平台 | 毛细管电泳仪 | PacBio 测序仪 |
| 引物 | 国标原始引物（扩增子 126~430bp） | 平台新引物（扩增子 450~550bp） |

**核心问题出现了**：国标的所有判定（Bin、参照样品、差异位点）都是基于"CE 读出的片段大小"。而平台测出的是序列。**两者怎么对上？** 这就是下一章。

### 5.5 本章小结

> 平台方法 = 多重 PCR + barcode 标记 + PacBio HiFi 测序 → 每样品一堆 reads（每条 = 一个位点的一段完整序列）。测序给的"序列"比电泳给的"长度"信息多，但和国标"对不上号"的问题需要解决。

## 第 6 章　两种方法怎么对起来（核心难点）

### 6.1 为什么不能直接比

先说结论：**平台读出的"序列长度" ≠ 国标电泳读出的"片段大小"**。原因有两个：

1. **引物不同**：同一个位点（比如 PM35），国标原始引物扩出的是 175~193 bp 的小片段；平台新引物扩出的是 ~500 bp 的长片段。**扩增子起点终点都不一样**，长度当然不同。
2. **平台不同**：CE 是按"迁移率"估长度（分子跑得快慢），和真实碱基数有系统偏差（通常差几个 bp）；测序是逐字母数出来的精确长度。

所以，"平台测到 PM35 位点这段序列长 520 bp"**不能**直接去和国标 Bin 的"175~193 bp"比。需要用一座"换算桥梁"。

### 6.2 三座桥（三个解决思路）

**桥 A：模拟国标原始引物的扩增子（推荐主方案）**

国标表 1 的原始引物序列是已知的。如果能在序列里找到原始引物"贴合"的位置，就能把"平台扩增子"裁成"国标扩增子"：

```
平台扩增子（~520bp）：
┌──────────────────────────────────────────────┐
│ 引物F2  [────── SSR重复区 ──────]  引物R2     │
│        ↑按国标原始引物位置裁一刀↑               │
└────────┴──────────────────────┴──────────────┘
    截出的这段（~180bp）＝ 国标CE会读到的长度
```

然后把这个"模拟长度"去对国标的 Bin → 直接可比。前提是参考序列里能找到原始引物的结合位置（需要从平台参考序列的"原引物标注"或比对玉米参考基因组来确定）。

**桥 B：数重复单元（交叉验证）**

SSR 的本质差异是**重复次数**。可以直接数出这段序列里 `GA` 重复了几次，用"重复次数"作为等位基因的代号。这个方法不依赖绝对长度，可以和桥 A 互相印证（比如：重复 6 次 ↔ 长度落在某个 Bin）。

**桥 C：用 CE 对照校准（最硬的验证）**

如果同一批样品同时用国标方法（CE）测过，就能建立"平台序列长度 → CE 片段大小"的换算公式（每个位点一个偏移量），并用真实 CE 结果验证平台分型的对错。**这是最有说服力的合规证据。**

### 6.3 参照样品（国标概念）

国标里有个概念叫**参照样品（reference control sample）**——一个"等位基因片段大小已知"的样品，用来给每次电泳"校尺子"，消除不同批次的误差。在平台方法里，也建议放几个已知品种做"定标样品"，让换算桥梁更可靠。

### 6.4 本章小结

> 平台(序列) 和 国标(长度) 不能直接比，靠三座桥：A 模拟原始引物扩增子（主）、B 数重复单元（辅）、C CE 对照校准（验证）。**本项目评估的核心，就是把平台数据经这三座桥换算成国标可比的形式。**

## 第 7 章　数据长什么样（fastq → 分型表）

这一章带你认识分析链条上每一层数据。**这是你评估平台输出时要知道的"数据地图"。**

### 7.1 从原始数据到结果的链条

```
① fastq（原始read）
   └─► ② 比对：把每条read贴回"参考序列"，确认它属于哪个位点
        └─► ③ 位点序列：每个样品×位点的所有read
             └─► ④ 等位基因：数重复/量长度，读出这个位点的"版本"
                  └─► ⑤ 分型表：样品×40位点的等位基因表格
                       └─► ⑥ 判定：和标准/参照比，得出合规结论
```

**① fastq**：测序仪输出的原始文件。一条 read 长这样（第 2 行就是 DNA 序列）：
```
@20260702_..._Run0003/254014/32-484
GGCCAAAAGGAAGGCCATAAGAGGAATGATGTCCGCGAAG...
+   
ZBAq'cYB@@ACA@?...（质量分数）
```

**② 比对（alignment）**：把每条 read 与 40 个位点的**参考序列**比对，看它来自哪个位点。参考序列是每个位点已知的代表性序列（平台已提供，且经 Sanger 验证过）。

**③ 位点序列**：按"样品 × 位点"把 read 分好类。比如样品 3 在 PM35 位点有 150 条 read，每条都是这个位点的一段。

**④ 等位基因**：对同一位置的多条 read，读出一致性（大家是否都长一样？）→ 判断是纯合还是杂合、重复几次/多长。HiFi 精度高，几百条 read 足够可靠地判定。

**⑤ 分型表**：最终结果是一张表：

| 样品 | PM01 | PM02 | … | PM40 |
|---|---|---|---|---|
| MP19548-1-1 | 320/350 | 234/240 | … | 283/310 |
| MP19548-1-2 | 320/320 | 240/252 | … | 299/310 |

每个格子就是该样品在该位点的等位基因（两个数字 = 两个版本的长度）。

### 7.2 平台现有 consensus 输出：一个重要的现实问题

平台目前对每样品会产出几条 **consensus（共识序列）**——把一堆相似的 read 合并成一条代表性序列，并附频率表、可疑位点表、QC 图、Sanger 峰图。

但**实测发现一个问题**：

> 平台现在的 consensus 输出，每个样品只覆盖了 **1~3 个位点**（比如某样品 2000 多条 read，只把其中占 7% 的主簇做成了 consensus）。而一个样品实际含 40 个位点的 read。

也就是说：**想靠平台现成的 consensus 直接拿全 40 个位点，是拿不到的。** 合规评估必须回到**原始 fastq**，把每个位点的 read 都找出来重新分型（就是 7.1 的 ②~④ 步）。这一点决定了项目的技术路线。

### 7.3 本章小结

> 分析链条：fastq → 比对 → 位点序列 → 等位基因 → 分型表。**平台现成 consensus 只覆盖 1~3 个位点/样品，不够用；需要从原始 reads 重新分型。**

## 第 8 章　怎么判定"符不符合国标"

分型表出来后，最后一步是**判定**。国标规定得很清楚。

### 8.1 真实性验证：数差异位点

国标 9.1：把检测样品和**标准样品**（代表该品种的实物/指纹）在 40 个位点上逐个比较，数出**有几个位点不一样**。

> **判定规则：差异位点数 ≤ 2 → 真实性成立（是同一品种）；> 2 → 不成立（不是它标称的品种）。**

国标还允许**序贯检测**（5.2.1）：先测 I 组 20 个位点——

- 若已经查出 ≥ 3 个差异位点 → 直接判不符，不用再测；
- 若 0~2 个差异 → 不确定，继续测 II 组，凑满 40 个再数总数。

### 8.2 真实性身份鉴定：指纹库比对

如果目的是"查这个样品是谁"（而不是验证它声称的名字），则用 40 个位点全测，和**审定品种 SSR 指纹数据库**比对，**零差异**匹配到某个品种即确定。这个需要有国标指的"SSR 指纹数据比对平台"（品种指纹库）。

### 8.3 纯度测定：数异常个体

纯度测的是"一批种子纯不纯"。国标做法：**单粒/单株独立检测**若干个体（杂交种 ≥96×2 粒，自交系 ≥96×4 粒），用 8 对候选纯度引物（表 3）筛出的 1~3 对引物，识别出**异常个体**（自交、异交、混杂），然后：

```
纯度(%) = 正常个体数 ÷ 检测总个体数 × 100%
```

判定时用 **GB/T 3543.1 的容差表**（国标 9.2）：检出率要在允许的抽样误差范围内。

> 注意：纯度要求"逐个个体独立检测"。如果平台是按"单样品=barcode"做的，**只要 96 个 barcode 对应 96 个独立个体**，数量就正好满足"96×2"的要求；如果是混合样，纯度测定做不了。**这个需要和客户确认（第 10 章）。**

### 8.4 报告怎么写

国标第 10 章给出了报告模板，例如真实性验证：

> "通过 ____ 对引物，采用 ____ 电泳方法进行检测，与标准样品比较未能检测出位点差异。"
> 或 "……检测出差异位点数 ____ 个，差异位点的引物编号为 ________。"

纯度报告：

> "通过编号为 ____ 的引物，检测了 ____ 个个体，……品种纯度为 ____%。"

平台要出具"符合国标"的检测报告，格式上也要能填进这些模板。

### 8.5 本章小结

```
真实性验证：差异位点数 ≤ 2 → 成立（可序贯：先I组20个，拿不准再测II组）
身份鉴定：40位点全测，指纹库零差异匹配
纯度测定：单粒检测 ≥96×2(杂交种)/96×4(自交系) 个体 → 异常个体比例 → 对照GB/T 3543.1容差
报告：按国标第10章模板填报
```

                │

### 9.2 名词表（随时查）

| 术语 | 一句话解释 |
|---|---|
| **DNA** | 遗传说明书，由 A/T/C/G 四个字母串成 |
| **碱基对 bp** | DNA 长度单位（一对字母）；"320 bp"=320 个字母长的片段 |
| **基因** | 说明书里一段有功能的文字 |
| **基因组** | 整本说明书（全部 DNA），玉米约 23 亿 bp |
| **染色体** | 说明书的分册；玉米 10 对（20 条），父本+母本各一份 |
| **等位基因 allele** | 同一位置的两个"版本"；SSR 检测中等位基因用片段大小表示 |
| **纯合 / 杂合** | 两版本相同 / 两版本不同 |
| **SSR（微卫星）** | 基因组里"小单元重复"的段落；重复次数不同→可区分品种 |
| **位点 locus** | 一个 SSR 所在的位置；本项目有 40 个位点 PM01~PM40 |
| **引物 primer** | 两段短 DNA，"书签"，贴在目标片段两头让 PCR 从这复制 |
| **扩增子 amplicon** | 两引物之间被 PCR 放大出来的那段 DNA |
| **PCR** | DNA 复印机，把目标片段复制几百万份 |
| **电泳 / 毛细管电泳 CE** | 按 DNA 片段长短排队；CE 精度 1 bp，读出"长度" |
| **Bin** | 一个位点上某个等位基因的"片段大小区间"；长度落进同一 Bin = 同一等位基因 |
| **峰 peak** | 电泳图上的信号尖；纯合=1 峰，杂合=2 峰 |
| **barcode** | 贴在每个样品上的 DNA"标签"，测序后按它把数据分回样品 |
| **read（读段）** | 测序仪读出的一条 DNA 片段序列 |
| **fastq** | 存 reads 的文件格式（名字+序列+质量） |
| **consensus（共识序列）** | 一堆相似 reads 合并成的一条代表性序列 |
| **比对 alignment** | 把 read 和参考序列对位置，确认它来自哪、在哪个位点 |
| **参考序列/参考基因组** | 用作比对基准的已知序列；本项目用 40 个位点的参考序列 |
| **标准样品** | 代表某审定品种的实物种子/指纹，真实性验证的比对对象 |
| **参照样品** | 片段大小已知、用于"校尺子"的样品 |
| **差异位点** | 检测样品和标准样品在某位点等位基因不一样 |
| **HiFi（CCS）** | PacBio 的高精度长读测序，单条 read 准确率>99.9% |
| **OD260/280** | DNA 纯度指标，1.8~2.0 为合格 |
